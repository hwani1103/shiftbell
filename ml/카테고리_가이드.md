# 메모 자동분류 카테고리 가이드

> `메모_자동분류_ML_계획.md`의 범주 설계(Phase 0)를 데이터 생성/검수용으로 옮긴 것.
> 데이터를 만들거나 라벨을 검수할 때 항상 이 정의와 우선순위를 기준으로 판단한다.
>
> ⭐ 2026-09-01 - 9개+기타(10종) -> 16개+기타(17종)로 확장. "운동" 아이콘(아령)이
> 달리기/수영/등산까지 뭉뚱그리는 게 아쉽다는 피드백으로 이 3종을 분리하고, 같은
> 원리로 "여가/휴식"에서 문화생활(영화/공연/전시)을, "기타"에서 자주 빠지던
> 금융(은행 용무)/집안일(청소·빨래)을 분리했다. 신설 근거는 전부 실측 데이터
> (아래 "신설 카테고리(2026-09-01)" 절 참고)에 기반함 - 반려동물/육아/여행은
> 후보로 검토했으나 기존 "관계·목적이 카테고리를 결정한다" 원칙(가족/쇼핑/사교
> 우선순위)과 정면으로 부딪혀서(예: "강아지 사료 사기"는 쇼핑, "강아지랑 공원
> 산책"은 여가, "친구랑 강아지 카페"는 사교로 이미 잘 나뉘어 있었음) 제외함.

## 카테고리 정의 (18개 + 기타)

| 카테고리 | 정의 |
|---|---|
| 업무 | 구체적 업무 이벤트(회의/보고/마감/출장). 근무 시간대 자체가 아니라 "근무 중 특정 이벤트"에 한정 |
| 공부 | 자격증/시험/강의/독서/스터디 등 학습 활동 |
| 운동 | 신체 활동 자체가 목적이되, 달리기/수영/등산/자전거/요가·필라테스가 **아닌** 종목(헬스/구기 등). 강도·훈련 의도가 드러나면 이쪽 |
| 달리기 | 러닝/조깅/마라톤. 강도·목적(가볍게 vs 훈련)과 무관하게 이 종목이면 전부 여기(운동과 갈릴 일이 없어짐) |
| 수영 | 수영장/바다 등에서의 수영. 강도·목적과 무관하게 전부 여기 |
| 등산 | 등산/트레킹/산행/둘레길. 강도·목적과 무관하게 전부 여기 |
| 자전거 | 자전거/따릉이 등 라이딩. 강도·목적과 무관하게 실제로 타면 전부 여기(2026-09-03 신설) |
| 요가/필라테스 | 요가/필라테스/스트레칭. 강도·목적과 무관하게 전부 여기(2026-09-03 신설, "필라테스"는 기존 운동에서 이쪽으로 승격) |
| 병원·건강관리 | 진료/약/검진/치과/헌혈 등 관리·치료 목적. 단련이 목적이면 운동, 관리/치료가 목적이면 이쪽 |
| 식사 | 끼니 관련, 사람을 만나는 게 목적이 아닌 경우 |
| 약속/사교 | 사람을 만나는 것 자체가 목적. 활동이 곁들여져도 만남이 핵심이면 우선(가족 다음으로 우선순위 높음) |
| 가족 | 가족 구성원(부모/형제/배우자/자녀/친족)이 대상이면 최우선 |
| 쇼핑 | 구매/장보기 |
| 여가/휴식 | 취미·카페·나들이(능동) + 낮잠·늘어지기(수동) 통합. 문화생활(영화/공연 등 구체적 콘텐츠 감상)은 아니면서 목적이 힐링/기분전환/놀이면 이쪽 |
| 문화생활 | 영화/공연/전시/콘서트/뮤지컬 등 구체적 콘텐츠 감상이 핵심. 넷플릭스처럼 명시적 키워드가 없어도 "콘텐츠를 본다"는 문맥이면 ML이 이쪽으로 학습돼 있음 |
| 금융 | 은행/적금/예금/환전/연말정산/공과금 등 개인 금융·행정 용무. 회사 업무 성격(법인카드 정산 등)이면 업무로 남음 |
| 집안일 | 청소/빨래/설거지/분리수거 등 직접 하는 집안 잡무. 청소기·빨래바구니 등 **도구를 사는 행위**는 쇼핑, 본가/부모님 댁에서 하면 가족(우선순위 유지) |
| 미용 | 미용실/네일샵/왁싱/염색 등 사람 대상 뷰티 케어. 화장품 구매는 쇼핑, 자격증 취득 목적이면 공부 |
| 기타 | 위에 명확히 속하지 않거나(생활 잡무, 막연한 메모), 모델 확신도가 낮을 때 |

## 우선순위 규칙 (라벨 충돌 시)

**가족 > 약속/사교 > (운동/달리기/수영/등산/자전거/요가·필라테스/공부/식사/
업무/쇼핑/집안일/미용/금융/문화생활 등 활동 특정형) > 여가·휴식 > 기타**

⚠️ 이 순위는 "누구와 관련됐나"가 충돌할 때(가족 vs 사교) 쓰는 것이지, "무엇을 하나"가
명확한 활동(쇼핑, 운동 등)에는 가족 구성원이 언급됐다는 이유만으로 적용하지 않는다.
(아래 쇼핑↔가족 항목 참고)

## ⚠️ 라벨링 시 주의 (2026-08-26, 실사용 데이터로 발견)

**"형/누나/언니/오빠/동생"은 혈연이 아니라 친한 사람을 부르는 호칭으로도 매우 흔히
쓰인다.** "친한 형 가게 오픈해서 축하금 송금"은 친형이 아니라 가까운 지인을 뜻하며
가족이 아니라 사교로 분류해야 함. 문장만 보고 판단하기 어려우면 문맥(가게를 차린
사람이 나이 차이만 있는 지인인지, 실제 가족 행사인지)을 보고 정하고, 정 애매하면
기타로 두는 게 낫다.

## 자주 헷갈리는 경계 (판단 기준)

| 경계 | 기준 |
|---|---|
| 운동 ↔ 여가/휴식 | 강도·훈련 의도(땀날 정도, 왕복 횟수, 정상 정복 등)가 명시되면 운동. "살살", "바람쐬러", "슬슬" 등 힐링/놀이 뉘앙스면 여가 |
| 가족 ↔ 약속/사교 | 만나는 대상이 직계/친족이면 가족. 친족이 매개했어도 실제로 만나는 대상이 비친족이면 사교 |
| 식사 ↔ 약속/사교 | 문장의 핵심 목적어가 "먹는 것"이면 식사, "누구를 만나는 것"이면 사교 (식사가 곁들여져도) |
| 업무 ↔ 공부 | 회사 업무를 위한 산출물/보고 성격이면 업무, 개인의 학습·자격 취득이 목적이면 공부 |
| 쇼핑 ↔ 가족 | **핵심 동사가 "사다/주문하다/구매하다"면 대상이 가족(아이 옷, 부모님 선물 등)이어도 쇼핑.** "가족 우선" 규칙은 가족↔사교(누구를 만나느냐)에만 적용되고, 가족↔쇼핑(뭘 하느냐)에는 적용 안 됨 — 구매 행위 자체가 핵심이면 쇼핑 |
| 여가/휴식 ↔ 문화생활 | 영화/공연/전시 등 구체적 콘텐츠를 감상하는 게 핵심이면 문화생활, 그런 콘텐츠 없이 막연히 쉬거나 노는 거면 여가 |
| 문화생활/등산/달리기/수영 ↔ 약속/사교 | 동호회/모임/클럽/뒷풀이/신년회 등 "사람이 모이는 자리"라는 신호가 있으면 사교가 우선(활동 자체보다 만남이 핵심) |
| 달리기/수영/등산 ↔ 쇼핑 | "러닝화/수영복/등산화/등산스틱을 산다"처럼 장비 구매가 핵심이면 쇼핑, 실제로 그 활동을 하는 거면 해당 스포츠 카테고리 |
| 집안일 ↔ 쇼핑 | "청소기/빨래바구니를 산다"처럼 도구 구매가 핵심이면 쇼핑, 직접 청소/빨래하는 행위 자체면 집안일 |
| 금융 ↔ 업무 | 개인 은행·재정 용무면 금융, 회사 업무의 일환(법인카드 정산 등)이면 업무 |
| 미용 ↔ 공부/쇼핑 | 자격증 취득이 목적이면 공부, 화장품/미용 가전 구매가 핵심이면 쇼핑, 미용실·네일샵 등 서비스 이용 자체면 미용 |
| 자전거/요가·필라테스 ↔ 쇼핑 | "자전거 헬멧/요가매트를 산다"처럼 장비 구매(사기/사주기/구매하기/장만하기 등)가 핵심이고 실제로 타거나 수업에 참여하는 동작이 없으면 쇼핑, 구매 뒤에 실제로 타거나("~사서 라이딩") 연습/수업이 이어지면 해당 카테고리 |
| 자전거 ↔ 기타 | "자전거 브레이크 수리 맡기러 가기"처럼 정비/수리만 맡기고 실제로 타는 동작이 없으면 기타(차량/기기 정비와 동일 원칙 - 전용 카테고리 없음) |
| 자전거/요가·필라테스 ↔ 약속/사교 | 동호회/모임 신호(동호회/모임/뒷풀이 등)가 있으면 사교 우선(달리기/수영/등산과 동일 원칙) |
| 자전거/요가·필라테스 ↔ 공부 | "자격증"(생활체육지도자/요가 지도자 등) 취득이 목적이면 공부 |
| 자전거 ↔ 운동 | "하늘자전거"(누워서 다리로 페달 돌리는 실내 운동 동작)는 실제 자전거가 아니라 운동으로 남음 |

`data/boundary_cases.jsonl`에 위 경계마다 실제 예문 + 판단 근거를 넣어뒀다.

## 신설 카테고리(2026-09-03) 판단 근거

**자전거**, **요가/필라테스**(스트레칭 포함) 2종을 달리기/수영/등산과 완전히
같은 원리로 신설함 - 강도·목적과 무관하게 그 활동이면 무조건 이 카테고리.
"필라테스"는 기존에 SPORTS_KEYWORDS(운동)에 있었으나 이번에 전용 카테고리로
승격하며 거기서 제거함. 기존에 "자전거 타고 슬슬 한바퀴"(여가/휴식)와
"자전거로 강변 전력질주"(운동)처럼 강도로 갈라놨던 boundary_cases 예문들도
달리기/수영/등산 신설 때와 동일하게 재해석 - 이제는 둘 다 "자전거"
카테고리로 수렴함("요가원 가서 명상 위주 수업" vs "근력 위주 수업"도 동일).

`ml/keyword_router.py`의 CYCLING_KEYWORDS/YOGA_KEYWORDS_* 주석에 하드매핑
설계(구매/수리 문장 defer, "필요가 있다" 오탐 방지 등)가 자세히 있음.

## 신설 카테고리(2026-09-01) 판단 근거

7종 모두 데이터로 검증 후 추가함(`ml/relabel_v2.py`로 기존 5,464개 라벨 데이터에
새 하드매핑을 그대로 적용해본 결과 기준):

- **달리기/수영/등산**: 기존에도 "등산"/"수영"/"조깅"/"러닝" 단어가 낀 문장의
  절대다수(등산 33/45, 수영 37/42, 조깅 9/9, 러닝 26/31)가 이미 "운동"으로
  라벨돼 있었음 - 즉 사실상 이미 "운동"의 하위집합으로 취급되던 걸 독립시킨 것.
  기존엔 "수영/등산이 여가/휴식과도 갈릴 수 있어서" 하드매핑을 일부러 안 걸었지만
  (강도/목적에 따라 두 카테고리 중 하나를 억지로 골라야 했음), 전용 카테고리가
  생기면서 그 딜레마 자체가 사라짐(강도·목적과 무관하게 "이 종목이면 무조건 이
  카테고리").
- **문화생활**: "영화"/"뮤지컬"/"공연"/"전시"/"콘서트"가 낀 문장도 절대다수가
  이미 "여가/휴식"이었음(영화 17/21, 뮤지컬 10/10, 공연 3/3, 전시 8/13, 콘서트
  3/4). "여가/휴식" 아이콘(야자수)이 너무 뭉뚱그린다는 것과 같은 문제라 분리.
- **금융/집안일**: 마땅한 카테고리가 없어 "기타"로 자주 빠졌던 것(은행 용무
  7/11, 청소·빨래·분리수거류 다수)을 전용 카테고리로 승격 - "기타"가 과도하게
  넓어지는 문제(코드 주석 `ml/keyword_router.py`의 ACTIVITY_PREFIX_KEYWORDS
  참고)를 완화.
- **미용**: 기존 데이터에 순수 인간 대상 미용 표현(미용실/왁싱/염색/속눈썹)이
  전혀 없어서(0건) 완전히 새로 만든 카테고리 - 반려동물 미용("반려동물 미용
  시켜주기" 등, 실측 40건+)과 충돌하지 않도록 "미용실"/"네일아트"/"네일샵"
  같은 구체적 복합어만 키워드로 쓰고 bare "미용"은 절대 안 씀.

⭐ pilot_dataset.jsonl은 원래 400개(Phase 1)였다가 Phase 5에서 5,230개로,

## 하드매핑 어미/앞말 대응 (2026-09-01 2차 점검)

실측 결과 기존 데이터에 "하자"/"할거임"/"해야됨"/"할까"류 캐주얼한 표현이
사실상 전무했던 것(전부 합쳐 5건 미만)과, RUNNING/SWIMMING/HIKING/CHORE
키워드가 "새벽러닝"/"주말등산"처럼 앞에 다른 말이 붙은 경우를 놓치는 걸
발견해서 `ml/keyword_router.py`의 `_verb_word_matches_token`을 두 방향으로
넓힘:

- **어미(뒤)**: "하다" 활용 어간을 하/해 2개에서 하/해/할/했/한 5개로 확장 -
  "청소하기"(하)/"청소해야됨"(해)뿐 아니라 "청소할거임"(할)/"청소했음"(했)/
  "청소한 적"(한)도 인정.
- **앞말(접두)**: RUNNING/SWIMMING/HIKING/CHORE_KEYWORDS는 `anywhere=True`로
  바꿔서 어절 맨 앞이 아니어도(=키워드 앞에 다른 말이 붙어도) 인정 - "새벽
  러닝"/"주말등산"/"저녁설거지" 같은 흔한 시간표현+활동 붙임 표기를 잡을 수
  있게 됨. **BEAUTY_PREFIX_KEYWORDS("펌"/"커트")는 이 확장에서 일부러
  제외** - "컨펌하기"(confirm, 업무 용어)처럼 "펌"이 무관한 단어 뒤에 우연히
  붙는 실제 충돌이 있어서 이 두 키워드만 여전히 어절 맨 앞에서 시작할 때만
  인정함("숏커트"처럼 놓치는 경우가 생기지만, 그 대가로 "컨펌" 오탐을 막는
