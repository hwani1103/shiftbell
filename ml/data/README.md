# Phase 1 파일럿 데이터

`카테고리_가이드.md`의 정의/우선순위 규칙에 따라 직접 작성(사람이 손으로 쓴 것,
LLM 대량생성 아님). 총 500개, 중복 문장 없음.

| 파일 | 개수 | 용도 |
|---|---|---|
| `pilot_dataset.jsonl` | 400 | 카테고리별 순수 예문(범주당 35~55개, 기타는 다양성 확보 위해 55개) |
| `boundary_cases.jsonl` | 40 | 6개 경계쌍(운동↔여가, 가족↔약속, 식사↔약속, 업무↔공부, 병원↔운동/여가, 사교↔운동) 각각 정답 라벨 + 판단 근거(`rationale`) 포함 |
| `eval_holdout.jsonl` | 60 | 학습에 절대 섞지 않는 평가 전용 세트. 범주당 6개, 의도적으로 짧고 축약된 문체(타이핑하듯)로 pilot_dataset과 다른 스타일 |

**학습에 쓰는 것**: `pilot_dataset.jsonl` + `boundary_cases.jsonl` (440개)
**평가만 하는 것**: `eval_holdout.jsonl` (60개) — 이 세트로 정확도가 크게 떨어지면
"학습 데이터 특유의 문체에 과적합" 신호로 본다.

## 다양성 확보를 위해 넣은 것

- 직접 키워드형("헬스장 가서 웨이트") + 간접 표현형("퇴근하고 땀 좀 빼고 들어가기") 혼합
- 길이 다양화: 3~4어절 단문 ~ 긴 문장
- 시간 표현 다양화(오후 2시 / 아침 / 자기전에 / 새벽 / D-3 등)
- 구어체·축약형(GX, PT, 코테, 인강), 영어 혼용
- `기타`는 잡무·막연한 감정 메모·확신도 낮은 사례 위주로 55개(다른 범주보다 많이 확보)

## 아직 안 한 것 (Phase 2에서)

- 오타 주입, 이모지, 노스페이스(공백 없는 표기) 변형
- 5,000개 규모 확장(LLM 대량생성 + 사람 검수)
- 실사용자 문체 반영(v1은 전부 개발자가 상상해서 쓴 것)
