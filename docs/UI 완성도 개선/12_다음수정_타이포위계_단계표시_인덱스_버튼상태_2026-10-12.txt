사용자 지시: 현재 dev debug 빌드는 변경하지 않고 마무리한다. 아래 요청은 기록만 하며 다음 수정에 함께 반영한다. 이번 원장 생성으로 제품 UI 값을 수정하지 않는다.

1. 온보딩 단계 표시 1/3·2/3·3/3
현재 너무 작다. 현재 숫자에서 임의로 폰트 값을 조금 올리지 않는다. 공통 타이포 계층에서 현재보다 한 단계 큰 재사용 가능한 역할/크기를 사용한다. 적합한 역할이 없으면 중앙 타이포 체계에 먼저 정의하고 단계 표시가 이를 참조하도록 한다.

2. 패턴 근무명 칩 인덱스
현재 좌상단 숫자가 너무 작다. 근무명 중앙 영역을 침범하지 않는 범위에서 최대한 크게 한다. 위치·여백·안전 영역·번호 두 자리·폰트 실제 측정을 함께 고려한다. 온보딩 로컬 fontSize 수정으로 끝내지 않고 모든 재사용 indexed chip의 공통 규칙으로 정의한다. 시스템 텍스트 배율 고정 계약 유지.

3. 날짜별로 직접 지정 버튼
활성/비활성인지 불명확한 현재 색상 조합을 제거한다. 현재 구현은 공통 AppUiButton의 quiet 역할(표면 배경/보조 텍스트 색)이며 화면별 하드코딩 색상은 아니다. 보조 행동을 약하게 표현하려는 역할 선택이었으나, 실제 활성 상태가 불분명하다는 사용자 피드백을 반영해 공통 역할·상태 정책을 개선한다. 활성 버튼과 비활성 버튼은 재사용 구조에서도 분명히 구분되어야 한다. 같은 문제가 다른 버튼에 생기지 않도록 공통 정책과 적용 위치를 확인한다.

4. 앱 전반 타이포 위계
메인 문구, 섹션 제목, 보조 안내, 더 작은 메타 정보 등의 위계를 공통 크기·굵기·색상 역할로 체계화한다. 화면마다 fontSize/fontWeight/color를 임의 조정하지 않는다. 기존 AppTypography 역할을 전수 확인하고 필요한 역할·중간 크기를 중앙에 정의한다. 현재보다 조금 크거나 작은 요청도 이 계층 안에서 해결한다.
