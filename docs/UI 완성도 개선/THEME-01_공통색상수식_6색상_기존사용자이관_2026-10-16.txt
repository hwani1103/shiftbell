구현
1. lib/theme/app_ui_theme.dart의 AppUiPalette.fromSeed가 16개 역할을 공통 생성한다.
   각 화면에서 색상표를 따로 관리하지 않는다. 고정 배색을 수식으로 바꾸므로 기존 배색의 세부 색감은 바뀐다.
   배경 기준색: 새벽 EDEDF8 / 아침 ECF8F7 / 주간 DFEDFC / 저녁354B67 / 다크1A1F2E.
   주간은 AppUiPalette.blueSeed, 나머지는 app_ui_time_palettes.dart에서 기준색 하나씩 수정한다.
   화이트는 주간 기준색에서 강조색을 계산하되 background/surface/soft를 흰색으로 고정한다.
   자동 시간: 05~08 새벽,08~11 아침,11~17 주간,17~21 저녁,21~05 다크. 기존 로컬 시계·복귀 갱신 유지.

2. 역할 목록과 계산 규칙
   background: 기준색(불투명), 화이트 모드는 흰색.
   surface: 밝은 배경에서 흰색72% 혼합, 어두운 배경에서5.5% 혼합.
            중간 명도의 어두운 배경은 글자 대비 극성이 바뀌지 않게 검정 방향으로 혼합.
   soft: background→surface65%, 화이트 모드는 흰색.
   primary: 기준색 HSL의 색상각 유지, 채도 .38~.65 제한, 밝은 화면 명도 .36 / 어두운 화면 .80.
   onPrimary: primary 위에서 대비가 더 높은 검정/흰색.
   text: 기준색 색상각, 채도 .20, 밝은 화면 명도 .14 / 어두운 화면 .96.
   secondaryText: text→background24% 혼합 후 대비 보정.
   border: text→background55% 혼합 후 경계 대비 보정.
   selectionOutline: 기준색 색상각+60도, 밝은 화면 명도 .38 / 어두운 화면 .82, 대비 보정.
   danger: 의미색 빨강 C23749를 밝기에 맞춘 후 대비 보정. 오류 의미는 배경색으로 치환하지 않는다.
   dangerSurface: background에 오류 빨강8% 혼합.
   disabledSurface: background→surface40% 혼합.
   disabledText: text→disabledSurface50% 혼합 후 대비3 이상.
   chipSurface/chipBorder/chipText: soft/border/text를 공유.
   AppUiColorMath는 여러 실제 배경에서 일반 글자4.5, 칩 경계3 이상의 대비를 보정한다.
   Material의 primary/secondary/tertiary 및 container, error, inverse 색도 같은 팔레트에서 파생한다.

3. 달력은 공통 기준색과 대비 계산을 공유한다.
   CalendarContrast는 AppUiColorMath에 위임하며 alphaBlend 후 대비를 계산하는 계약을 보존한다.
   CalendarReadingPalette의 날짜용 검정/흰색, 공휴일 빨강, 메모/카드/월 구분은 역할별 계산을 유지한다.
   달력 진한 띠도 고정 청회색 대신 배경색→검정65%로 계산한다.
   달력의 크기·행·글자 측정·패딩·근무명 점유율 및 저장 근무색/DB는 이번 작업에서 바꾸지 않았다.
   공휴일/오류 등 의미색, 사용자가 저장한 근무색, 고정 시스템 스플래시 #EEF6FD는 독립 계약이다.

4. 다음 알람
   NextAlarmTab 내부와 메인 외곽/하단 탭에 AppUiThemeScope를 연결한다.
   움직이는 그라데이션 배경을 삭제하고 clock/ring/track/date/remaining/type/empty/list/button/snackbar를 역할 색상으로 연결한다.
   알람 목록은 별도 AppUiThemeScope를 사용하여 열린 동안 색상 선택 및 시간 구간 변경에도 대응한다.
   알람 예약/종료/알림 권한 판정 로직은 변경하지 않았다.
   이번 main.dart 수정은 다음 알람(index0)의 외곽 팔레트 활성화와 달력 전용 변환 조건 분리뿐이다.

5. 기존 사용자 설정 이관
   CalendarThemeMigration의 screen_palette_migration_v2 완료 표식을 마지막에 저장한다.
   신규: 저장 테마 및 기존 권한/환영 표시가 없으면 automatic으로 시작하고 표식을 남긴다.
   기존: mainDark는 mainWhite(표시명 메인)로 통합하고 night(다크 고정), 그 밖에는 테마 유지 + originalWhite.
   과거 별도 고정 originalDark 값은 night로 치환한다.
   이전 화면색상 선택기에서 직접 저장한 고정 선택은 보존한다.
   V1에서 메인 고정 이관 후 자동으로 바꾼 기록, V2 이후 직접 고른 자동/고정 선택도 보존한다.
   시작 시 두 provider가 동시에 요청하는 이관은 직렬화하며, 부분 저장 후 재시도 가능하다.
   설정 저장 실패 시에도 읽을 수 있는 기존 선택을 화면에 적용하여 자동으로 잘못 전환하지 않는다.
   locale 기본 달력은 달력 provider가 결정한다. 색상 provider가 임의로 한국 기본 달력 ID를 쓰지 않는다.
