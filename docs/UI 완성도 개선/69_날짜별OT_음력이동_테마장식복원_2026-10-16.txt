UI69 — 날짜별 OT / 평일 음력 이동 / 휴대폰 테마 장식 복원 (진행 중)

요청
바탕화면 OT보는방법.txt를 전체 읽고 artifacts/calendar_ot_2026_10_16/OT보는방법_요청원문.txt에 보존. UI62/63의 검토안은 당시 기록이며 이번 사용자 확정 규칙이 우선한다.

적용
- 한글 실제 reading 달력의 OT를 기본 '+ 1h 30m' 형태로 표시. 0은 미표시, 정시 '+ 1h', 분만 '+ 30m'. 월 OT와 동일하게 수동 OT + 설정이 켜진 근무변경 증가분. 기존 DB/월합계/날짜 상세 표현은 변경 없음.
- CalendarDayOvertime는 schedule/manual map/근무변경설정이 같으면 날짜별 계산 재사용. 데이터 변경 때 새 캐시. 기존 인접월 선조회 유지.
- 음력 표본은 수→화→목→월→금, 공휴일이나 OT가 있으면 다음 후보. 주말 미표시, 평일 후보가 없으면 그 주 생략. 이동한 날짜의 실제 음력 사용. 달력 날짜 생성으로 월/연도 경계 처리.
- 기본 OT는 음력/공휴일 슬롯. 공휴일과 OT가 겹치고 메모0~2개인 메인/심플/소프트/뱃지는 3줄 메모의 맨 위 슬롯에 OT, 실제 메모는 아래에 순서 유지. 메인 OT는 배경 없이, 다른 세 테마 OT는 공통 메모 표면/테두리로 구분. OT를 메모 데이터로 저장하지 않음.
- 공휴일+OT+3메모는 근무칩 크기 보존, 공휴일 바로 아래 OT 한 줄. 날짜/메모는 기본 .96, 공휴일/OT는 .82 비율을 기준으로 실제 남은 높이에 추가 맞춤. 날짜>메모>공휴일=OT의 글자 위계. 축소 line metric 반올림에 한 줄1px 여유를 예약해 글자 누락 방지.
- 다크그리드/다이어리/언더라인/매거진은 공휴일이 함께 있을 때 별도 OT줄 아래로 메모를 이동. 남는 높이 우선 사용, 낮은 셀에서만 축소. 다크그리드 날짜 오른쪽 전체 공휴일 표기와 휴무 흰 글씨(UI68) 유지.
- 이벤트는 날짜 오른쪽. 같은 메모 기준 글자 크기로 실제 폭을 재서 '+ 1h 30m'→'+1h 30m'→'+1h30m'→'1h30m' 순서로 최소한만 변경. 그래도 넘으면 마지막 표기를 안쪽에 fit.
- 일반 휴대폰 다이어리 오늘 날짜는 근무명 왼쪽 비대칭 둥근 테두리 복원. 매거진은 좌상단 근무색 삼각형/우측 날짜 복원. AppLayout.usesBoundedCalendar 폴더블 경로는 종전 장식 유지.
- 미리보기, CALENDAR_THEME_MODE 복구 경로, 외국어 OT 표시 범위는 확장하지 않음.
