독립 게임 포탈 UI 후속 — 2026-10-14

GAME-06의 간결한 UI 유지. LEVEL/메뉴, 보드, 공별 남은 횟수, 되돌리기/출발.
포탈: GameSkin.portal 역할색(밝은/어두운 테마 대비), IN의 동심원·안쪽 화살표, OUT의 끊어진 링·바깥 화살표, IN/OUT/∞번호. 색상만으로 입출구를 구분하지 않는다.
경로: IN에서 실선 끊고 OUT에서 이어서 그림. 출구에 편집 커서와 갈 수 있는 칸 표시. 되돌리면 이전 끝점으로 복귀. 잘못된 마지막 선택의 빨간 표시는 실제 도착 출구에 그린다.
전이 펄스: 논리 PortalEvent의 정확한 시각에서 시작, 시간 지연 없음. 동작 줄이기에서는 생략. 캐시된 텍스트/렌더 리소스는 보드 dispose 때 정리.
공: 이미지 추가 없이 기존 Canvas 공/무늬/2축 회전 유지. 포탈 사이의 빈 공간에서는 회전하거나 미끄러지지 않는다.
도움말: 첫 포탈 레벨에 별도 규칙 안내, 기본/문 확인 상태와 독립 저장. 메뉴 도움말에서 재열람.
사용 중 발견한 경계 수정: 실행 메뉴의 다시 시작, 동일 경과 시간의 프레임별 누적 오차에 따른 도착 표시.
320x600에서51/55/60/70 및70 다크를 Flutter로 렌더해 확인. 기존44px이상 셀, 스크롤/시작 때 보드 위치 고정, 버튼 접근, 실패재시작, 저장복원을 자동 검사.
