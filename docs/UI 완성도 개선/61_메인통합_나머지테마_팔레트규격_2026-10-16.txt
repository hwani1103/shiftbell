메인 선택과 업그레이드
- 사용자에게 보이는 Main Dark 제거, Main White 이름은 메인(Main 등 5개 언어)으로 변경. mainDark enum은 옛 설정/백업 해독을 위해 내부에 보존하고 실제 선택값은 mainWhite로 정규화.
- 기존 mainWhite→화면색상 originalWhite(화이트), mainDark→originalDark(다크)를 최초 한 번 고정 적용. 시간 자동 선택으로 넘어가지 않음. 원래 선택을 별도 설정에 기록하고 마지막에 완료 표시를 저장.
- 이관 완료 후 사용자가 자동/다른 색상을 선택하면 이후 실행에서도 존중. 저장 중단 시 원래 ID 기록으로 재시도. 새로운 설치는 자동 선택 유지. 메인 외 테마 선택은 유지.
- 달력 ID 없이 사용하던 기존 한국어 기본 메인은 설치 이력으로 화이트를 보존. 해외 기본 Periwinkle은 메인으로 잘못 분류하지 않음.
- 저장된 근무색/사용자 지정색은 통합 과정에서 덮어쓰지 않음. 메인 색상 조회는 저장된 색을 먼저 사용. 다른 테마에서 메인으로 새로 선택할 때는 기존 기본색 적용 규칙 유지.
- 자세한 설정/백업 이관 계약은 next_version_27이후/17_THEME-01_메인통합_기존색상보존_2026-10-16.txt.
