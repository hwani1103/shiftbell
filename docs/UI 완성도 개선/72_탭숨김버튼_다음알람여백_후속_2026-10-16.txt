사용자 최종 요청: 수면회복·일정관리 탭 없애기 문구가 빨간 배경에 보이지 않는 문제 수정. 다음 알람 요소 간 여백을 조금 늘리고, 스크롤 없이 '이 알람 끄기'를 하단 탭 바 바로 위에 여백을 두고 배치. 두 곳만 추가 수정 후 빌드/최종 보고/컴퓨터 종료. 폰 추가 사용 없음.
UI71은 당시 설치 및 검증 증거로 보존하며 이번 발견과 수정은 별도 연결한다.

변경
- DisableTabButton의 배경/아이콘/문구가 모두 danger였던 오류를 공통 AppUiButton danger 역할로 교체. dangerSurface 배경/danger 글자·아이콘, 기존 오른쪽 정렬/확인·취소/탭 저장 콜백 유지.
- AdaptiveHeroLayout에 선택적 세로 잔여 공간 분배를 추가하고 다음 알람만 사용. 일반 폰은 기존 링의 높이 양보와 제한된 높이 구조를 유지하며 남는 공간을 요소 사이에 배분한다. 마지막 버튼 아래 공통 gap(기준16dp의 화면비 환산)을 유지. 접힘/펼침의 기존 분할·축소 방식은 보존.
- P0 권한·알람 기능/DB/출시 언어 리소스/달력 셀 변경 없음.

검증
- targeted_tests.log: 24검사 PASS. 6팔레트×2탭의 실제 렌더링 텍스트 대비4.5 이상/아이콘 대비 동일/확인 후 취소 시 콜백 미실행. 다음 알람 모든 팔레트의 하단 버튼 여백4~20dp/무스크롤/실제 폰트 렌더링 포함.
