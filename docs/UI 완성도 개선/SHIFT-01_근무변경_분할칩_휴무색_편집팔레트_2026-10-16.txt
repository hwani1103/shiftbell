최종 합의
- 원래 패턴 근무에서 변경된 날짜: 칩 왼쪽20%는 원래 근무 배경, 오른쪽80%는 변경된 근무 배경. 이름은 변경된 근무명만 표시.
- 글자도 동일한 전체 크기/위치로 그린 두 사본을 같은 경계에서 잘라 표시한다. 글리프 반쪽이 경계에 걸려도 그 부분만 해당 근무의 글자색. 양쪽 기존 글자색이 같으면 그대로 유지.
- 컬러뱃지(initialBadge), 미니멀언더라인(underline), 매거진(editorial)은 제외. 영어 추가2종 Periwinkle/Soft Mosaic 포함. 실제 달력에 적용하며 미리보기에는 변경 표시를 강제하지 않는다.
- 첫 휴무 인식 이름만 테마 전용 휴무색. 이후 휴무/휴가/연휴/Off/Leave 등은 일반 순서 배정에 포함. 랜덤 대신 결정적 순서를 사용.
- 편집 팔레트는 기존33색의 값/순서를 그대로 보존하고, 테마 기본색에서 충분히 다른7색만 추가하여40색. 44색 전부 추가/총77색은 중간 조사·초기 구현이며 최종 제품 정책이 아님.

구현
- calendar_shift_change.dart: 날짜별 원래 색/글자색 범위와 공통20% 분할. 클립은 레이아웃과 분리, 이름 줄바꿈/글자 축소 계산은 기존 ShiftChipLabel 그대로. 원래 색 사본은 입력/접근성에서 제외하여 탭과 읽기를 중복시키지 않는다.
- 달력에서 실제 근무와 패턴을 비교. 둘 다 유효하고 다른 경우만 활성화. 불규칙의 빈 패턴/미설정/같은 근무/변경 취소는 단색 유지. 편집 전 마지막 값이 아니라 원래 패턴이 기준.
- ContractCalendarCell/DetailCalendarCell/WideCalendarCell/GlobalConceptCalendarCell 및 기존 phone 렌더링 경로에 연결. 기존 크기/비율/모서리/텍스트 방식 유지. 메인 기존 검정 띠 제거.
- 반투명 심플/다이어리와 Soft Mosaic은 기존 테마의 배경색 변환을 원래 근무색에도 적용. Soft Mosaic만 기존 칩 방식대로 혼합 배경에서 글자색을 계산하며, 나머지는 기존 근무 글자색을 입력값으로 보존한다.
- Periwinkle은 변경일을 이어진 근무 띠에서 분리하여 그 날짜 안에 변경명/20% 원래색을 표시. 변경되지 않은 이웃 날짜의 기존 병합은 유지한다.
- _assignFromPalette는 shiftTypes 전체를 기준으로 첫 휴무만 별도색, 나머지는 순서 배정. 패턴 외 근무도 색이 존재한다.
- mainCalendarShiftColors는 기존 저장된 주간/야간/커스텀색 보존. 과거 자동 캐시에 남은 두 번째 이후 휴무 빨강만 미사용 일반색으로 보정. 명시적인 customShiftColors는 변경하지 않는다. 함수 계산이며 자동 DB 마이그레이션을 추가하지 않았다.
- 설정 색상 편집의 미리보기/사용 중 판단/저장 캐시 계산도 메인 달력의 보존 색상 함수를 사용하도록 일치시켰다. 기존 메인 다크 색을 보존한 사용자가 편집 화면에서 다른 기본색을 보거나 저장 시 다른 근무까지 재배정되는 문제를 피한다.
- kAdditionalEditorShiftColors에7색 중앙 관리, editableShiftColors로 기존 목록 뒤에 정확한 중복 없이 추가. 테마 기본 배정색 자체는6개로 줄이거나 바꾸지 않는다.
