UI70 — 다음 알람 세로 스크롤 / 공통 버튼 강조 (진행 중)

원인
THEME-01 팔레트/공통 버튼 적용 이후에도 일반 폰은 AdaptiveHeroViewport의 SingleChildScrollView와 고정238.w 링, 큰 위아래 간격을 유지했다. 공통 버튼48dp 최소높이를 포함한 실제 콘텐츠 합계가 남은 높이를 넘으면 실제 스크롤이 생겼다. 기존24px 이하만 막는 physics는 레이아웃 초과를 해결하지 못했다.

수정
- 일반 폰은 유한 높이 Column으로 바꾸고 링만 Flexible로 줄인다. 날짜/시간/설명/버튼 글자는 원래 크기, 버튼 최소높이48 유지. 간격은 공통 AppUiMetrics의 pagePadding/gap/compactCardPadding/dialogActionGap 사용.
- 폴더블/넓은 화면의 기존 조합과 fit 경로 유지. obsolete 미세스크롤 차단 physics 제거.
- AppUiButton에 emphasized 선택 인자(기본false). secondary는 primary/onPrimary, danger는 danger/onDanger의 채움 역할 사용. onDanger는 공통 색 계산의 ink(danger). 화면별 고정색/팔레트별 분기 없음. 두 알람 버튼만 opt-in. 기존 다른 화면 버튼 기본 표현 보존.
- 알람 삭제/종류변경/권한 상태/카드 갱신 흐름 변경 없음.

검증
