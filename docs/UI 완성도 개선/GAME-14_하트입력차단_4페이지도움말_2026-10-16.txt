사용자 요청과 구현
- 하트 0개: GameSessionController.editable에 잔여 하트 조건을 포함.
  일반 모드에서 공 선택/선택 해제/경로 입력/Undo/선택 경로 지우기/출발 차단.
  보드 접근성 탭도 목적지 목록이 비어 차단된다. UI 버튼도 비활성.
  하트 1개 회복 시 기존 타이머 알림으로 조작 가능 상태 복구.
  게임 메뉴/도움말/나가기는 접근 가능. 마지막 하트를 쓴 이미 시작된 재생은 계속된다.
  테스트 모드의 무한 하트 계약은 유지. 출시 전 테스트 토글 제거는 통합 단계 잔여.
- 하단 '다음 하트까지 N초' 문구/표시 코드 제거. 하트 내부 채움과 회복 시계는 유지.
- 선택 공의 경로 끝점 원은 편집 가능할 때만 그린다.
  출발/일시정지/결과 화면에서 마지막 공의 점과 경유지 깃발을 표시하지 않는다.
  기존 희미한 경로선과 실제 움직이는 공의 중심점은 별도 표현으로 유지.
- 도움말은 레벨과 관계없이 항상 4페이지:
  1/4 기본 규칙: 가로·세로 직선, 선택 횟수 제한, 모든 공의 별 도착, 충돌 탈락.
  2/4 돌아가기: 같은 속도에서 이동 거리로 도착 시간을 조절하는 일반 규칙.
  3/4 문과 스위치: 같은 색 연결, 시간 점, 다시 밟기와 동시 통과 규칙.
  4/4 포탈: IN/OUT, 끝점 선택으로 이동, 재사용/시간/충돌 규칙.
  이전/다음 버튼, 마지막은 확인. 이전은 첫 페이지에서 비활성.
  페이지 전환 시 본문 스크롤 위치 초기화. 작은 화면은 본문만 스크롤.
  기존 GameSkin 타이포와 GameMetrics 여백/버튼을 재사용.
- showIntro를 사용하는 호스트에서 처음 Lv1 진입 시 1/4 한 페이지만 표시.
  확인 또는 닫은 뒤 rulesSeen을 영속 저장. 재진입/프로세스 재시작 후 반복하지 않는다.
  문/포탈 레벨의 별도 자동 팝업은 제거. 전체 도움말은 메뉴에서 열 수 있다.
  일반 도움말 열람이 Lv1 최초 안내 상태를 소모하지 않도록 분리.
- 힌트 버튼/표시 상태 제거. 독립 호스트는 힌트 JSON을 읽거나 번들에 포함하지 않는다.
  기존 원본 pilot_copy.json, 풀이 검증 데이터, 정답경로 문서는 개발 증거로 보존.
  GameStrings의 한국어/영어 문구와 생성 부분 글꼴을 함께 갱신.
