스케줄 변경 창 빈 모달 — 공통 칩/사전 측정 충돌 회귀 (2026-10-15)

사용자 관찰
- 설정 → 편집 → 스케줄 변경에서 검정 반투명 배경만 뜨고 창이 나타나지 않음. 예전에는 정상.

원인
- 최근 공통 AppShiftChip이 단순 Text/FittedBox 경로에서 ShiftChipLabel로 변경됨. 새 라벨은 자동 글자 축소를 위해 LayoutBuilder에서 실제 칸 크기를 사용함.
- 기존 ShiftEditorDialog는 AlertDialog의 intrinsic/dry layout으로 Wrap/칩 크기를 미리 측정하려 하므로 이 경로와 충돌함.
- 실기기 로그: The _RenderLayoutBuilder class does not support dry layout, ShiftEditorDialog의 AlertDialog:19, 이후 RenderBox was not laid out 연쇄 오류. 배경 barrier만 보이는 원인임.
- 새 외국어 이름이나 문자열 손상이 원인이 아니라 공통 UI 개선의 기존 편집 창 호환성 회귀. 이 호환성을 이전 검사에서 놓쳤음을 사용자에게 설명함.

수정
- 공통 ShiftEditorDialog를 실제 제한 너비로 바로 배치하는 Dialog로 변경. 제목/내용을 Flexible+SingleChildScrollView에 두고 저장/취소는 별도 OverflowBar로 유지.
- intrinsic/dry layout을 요구하지 않아 반응형 칩이 실제 크기로 정상 배치됨. 작은 화면/키보드에서도 내용 스크롤 및 버튼 접근 유지.
- 기존 SettingsAppearance의 색/제목/본문 역할 유지. 대화상자 간격/반경은 공통 AppUiMetrics 토큰으로 정의.
- 일정 계산/조 변경 적용/근무명 저장/알람 로직은 수정하지 않음. 같은 공통 틀을 쓰는 이름/색 편집 창에도 적용되는 구조 변경임.
