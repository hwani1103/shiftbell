사용자 합의
- 기존 시스템 스플래시 아이콘 유지, 온보딩 공통 핵심 색상을 배경으로 사용.
- 최초에는 빌드 보류 지시를 따라 코드만 수정. 이후 오늘 선택 안내 수정까지 합쳐 dev debug 빌드 요청으로 재승인.
- 오늘 선택 안내는 처음에만 깜빡이고 멈추지 않도록 느리게 계속 반복.

스플래시
- 단일 원본: lib/theme/app_ui_theme.dart의 AppUiPalette.sage.primary (#44685A).
- Gradle generateAppUiPalette가 공통 Dart 팔레트에서 primary 값을 읽어 Android color resource를 빌드 시 생성.
- app_ui_splash_background는 생성된 app_ui_primary를 참조. XML에 색상을 별도로 하드코딩하지 않음. 공통 primary 변경 시 다음 Android 빌드에도 반영.
- Android12 이상 밝음/어두움 values-v31/values-night-v31 LaunchTheme.windowSplashScreenBackground 적용. 구버전 launch_background도 같은 resource 사용.
- 아이콘/마스크/아이콘 배경은 기존 시스템 기본값 유지. 문구나 별도 스플래시 페이지/추가 대기 없음.
- Android 시스템 스플래시는 Flutter 시작 전 native resource를 사용한다. 이는 현재 기본 팔레트의 빌드 시 연결이며 시간별 동적 시작 테마까지 구현한 것은 아님.

안내 모션
- 공통 AppUiMotion attentionCycle 2.4초. opacity1→0.65→1, 각 구간 easeInOut으로 부드럽게 연결.
- AppUiAttention 컨트롤러 repeat로 오늘 선택 대기 중 지속. 크기/위치/영역 변경 없음.
- 오늘 근무 선택 시 enabled false로 반복 즉시 중단하고 opacity1 고정. 패턴 수정으로 돌아가면 안내 widget이 제거되어 controller 해제.
- disableAnimations/accessibleNavigation 요청 시 반복하지 않으며, 설정 변경 시에도 재조회하여 중단/재개.
