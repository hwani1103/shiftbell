원인과 구현

- CalendarDateGridBorder를 TableCalendar.calendarStyle.tableBorder로 연결. 기존 CalendarDateGrid의 경계 규격을 실제 월 Table의 좌표로 그린다. 셀 전체 fit와 분리하고, 마지막 줄의 날짜 칸까지만 닫는 기존 계약 유지.

2. onPageChanged는 손을 놓기 전/페이지 경계 통과 시점에도 호출된다. 기존에는 부모 CalendarTab setState와 메모/OT DB 조회를 즉시 실행했고 조회 결과가 같아도 각각 새 Map 상태를 발행했다.
- 내부 TableCalendar 이동은 유지하고, 외곽 헤더/요약과 월 조회는 수평 ScrollEnd 이후 한 번 실행. 중첩 스크롤은 제외하고 빠른 재드래그 때 최신 월만 적용.
- MemoNotifier/OvertimeNotifier는 값이 같으면 상태 발행 생략. 메모는 조회 범위에서 삭제된 행도 제거하며 범위 밖 값은 보존한다.
3. _lineHeightOf가 날짜 셀마다 같은 TextPainter 측정을 반복하고 dispose하지 않았음.
- 최종 TextStyle+TextScaler별 높이 캐시 최대128, 측정 후 painter dispose. 글꼴/크기/leading/배율 변화는 다른 키로 재측정. 레이아웃 공식/폰트 크기 변경 없음.
- main 소스(version1.0.24+27)에서도 즉시 월 갱신/반복 텍스트 측정 경로 확인. 출시 설치본의 예전 대비 회귀 시점을 단정하지 않는다.
