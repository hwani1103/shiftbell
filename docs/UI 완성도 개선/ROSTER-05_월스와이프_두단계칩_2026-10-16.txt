사용자 지시
한 화면 보기 배치는 보존하며 월 이동을 최대한 매끄럽게 개선. 두줄보기는 ROSTER-04로 복원한 구조/둥근칩을 유지하되 기본칩은 조금 작게, 긴 이름은 현재 크기로만 확장. 두 단계 모두 근무명을 기존보다 조금 크게.

구현
- 월 전환의 부모 setState 제거. ValueNotifier로 년월 Text만 갱신하고 움직이는 PageView/기존 MonthShiftTable 인스턴스 보존.
- 페이지 기준 연월을 화면 진입 시 고정하고 오늘 이동은 현재 연월 인덱스를 다시 계산. 각 페이지의 오늘 강조 여부는 선택된 달이 아닌 해당 페이지 연월로 계산.
- 색상 맵은 페이지 빌더마다 반복 watch/생성하지 않고 상위 build에서 한 번 준비.
- 한 화면 보기는 불필요한 타임라인 치수 측정 생략. 두줄 날짜헤더 높이는 의존성/위젯 변경 때만 측정하고 셀마다 TextPainter 반복 생성 제거.
- 경계가 정해진 AppShiftChip은 사용하지 않는 자연크기 측정 생략. 기존 기본 크기/표현은 유지하고 labelFontScale/cellPadding을 선택 인자로 추가.
- AllShiftsTimelineMetrics: 기존 짧은 이름 기준 치수의94% 기본형/100% 확장형2개만 제공. 모든 이름이 작아진 내부 영역에서 기준글자의92% 이상으로 들어가면 기본형, 실제 너비/높이 때문에 더 축소해야 하면 표 전체를 확장형으로 맞춤. 문자 수 분기 없음. 더 긴 이름에도 추가 확장하지 않음.
- 두 단계 공통 글자 기준×1.08, 내부패딩3→2. 가독성 확대와 둥근반경10.r/테두리1.6/두블록/8.w 바깥여백/날짜단위스냅 유지. 한 화면 보기의 크기/폰트/배치는 수정 없음.
