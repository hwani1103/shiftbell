GAME-08 / 2026-10-15 / 독립 Sync Path Lab DEV

기준: GAME-07 및 game_implementation_v10의 70레벨. 기존 원장은 당시 증거로 보존한다.
이번 변경은 독립 게임 패키지와 실험 호스트에만 적용한다. ShiftBell 앱의 테마/온보딩/달력 UI 변경이 아니다.

조작
- 시작/초기화/저장 복원은 선택 없음. 공 또는 하단 무늬 버튼을 직접 선택한다.
- 선택한 공의 경로를 완성해도 다음 공으로 자동 전환하지 않는다.
- 공의 A/B/C/D 이름은 표시하지 않는다. 저장·엔진 ID는 호환성을 위해 유지한다.
- 명시한 모든 경로 끝점을 공별 고정 모서리의 깃발로 표시한다. 같은 칸의 네 공과 동일 공의 재방문을 함께 남긴다.

장치
- 포탈의 링/색/입출구 방향은 유지한다. IN/OUT/번호/무한 배지는 제거한다. 모든 포탈은 계속 재사용한다.
- 열쇠/열쇠구멍 문의 형태와 금색/자홍색으로 짝을 표현한다. 문이 열리면 문짝도 열린다.
- 눈금 하나는 한 칸 이동 시간이다. 계획 중에는 전체 지속 시간, 재생 중에는 엔진과 같은 남은 시간을 표시한다.
- 숫자로 장치를 구별하지 않는다. 좌표·이동량·한도·LV 같은 플레이 정보는 유지한다.

목록·진행
- LV 숫자만 표시한다. 런타임 제목/챕터 제목을 삭제한다.
- 초록→청록→금색→파랑→보라 그룹 안에서 색이 진해진다. 95~100은 옅은 빨강→진한 빨강이다.
- 배경 명도로 검정/흰색 글자를 선택한다. 카드 100개의 글자 대비는 4.5:1 이상으로 검사한다.
- 마지막으로 연 레벨에 파란 굵은 테두리. 목록 복귀/안드로이드 뒤로가기/재실행 때 해당 카드가 보이게 스크롤한다.
- 정상 모드는 순차 해금, 상단 고정 잠금 아이콘은 전체 레벨+무한 하트를 함께 켜고 끈다. 재실행하면 정상 모드다.

하트
- 레벨별 3개. 함께 출발에서 차감하며 소진된 하트는 반투명으로 남는다.
- 0개가 된 뒤 충전을 시작하고 3개까지 계속한다. 앱 안 60초/개, 앱 밖·종료 3600초/개다.
- 진행 중인 하트가 아래부터 채워진다. 동작 줄이기 설정에서는 보간 없이 상태만 갱신한다.
- 목록/다른 레벨에 있어도 소진된 각 레벨의 충전을 계속 계산한다.
- 테스트 모드는 잔량을 덮어쓰지 않고 차감만 생략한다.

공통 규칙
GameSkin / GameMetrics / CampaignColors / HeartMeter / GateVisual / paintWaypoints를 사용한다.
7열 이하는 최소44px 셀, 최종8열은320px에서 전체가 보이도록 최소38px 예외 토큰을 사용한다.
시스템 텍스트 배율과 무관한 기존 게임 UI 크기 계약을 유지한다.
