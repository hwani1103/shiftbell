최종 계약

- 입력 중에는 삭제 안내만 우측 상단에 표시. 빈 패턴 안내, 0/40, 오늘 날짜, 오늘 표시하기, 오늘 위치 안내는 표시하지 않는다. 내부40개 제한은 유지.
- 패턴 아래에 고정 액션 영역을 예약한다. 길어진 패턴은 그 위의 목록에서 스크롤하며 액션 영역으로 침범하지 않는다. 패턴 완성 버튼은0·1개일 때 비활성,2개 이상일 때 활성.
- 패턴 완성 버튼을 누르면 같은 버튼이 우측 하단으로 이동하며 패턴 수정으로 바뀐다. 오늘 선택 안내는 이동에 맞춰 나타난다. 파란 선택 테두리/정확한 반복 위치 선택/오늘 배지를 유지하며, 오늘 선택 후에만 다음: 알람 설정이 활성화된다.
- 완성 단계에서는 제공 근무명 추가와 패턴 삭제를 잠근다. 패턴 수정으로 돌아오면 오늘 위치를 무효화하고 편집을 다시 허용한다. 오늘 선택을 여러 번 눌러도 삭제되지 않는다. 알람 단계에서 Back 복귀해도 선택 모드를 보존한다. 오늘 선택 중 삭제 안내는 숨겨 서로 다른 지시를 동시에 보여주지 않는다.
- 알람 카드는 표시 전용 근무명 칩과 우측의 개수/알람 편집 버튼 그룹. 빈/등록 상태와 관계없이 같은 문구·버튼으로 유지한다. 공간이 좁으면 우측 그룹에서 줄바꿈하되 오른쪽 카드 여백을 지킨다. 정규·불규칙 동일 구현, 편집 팝업의 추가·삭제·타입·시간·취소·빈 목록 저장·5개 제한 유지.
