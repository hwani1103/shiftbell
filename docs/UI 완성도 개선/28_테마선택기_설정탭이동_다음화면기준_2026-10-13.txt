28. 테마 선택기 설정 탭 이동 / 다음 화면 기준 (2026-10-13)

사용자 요청
- 온보딩 1/3에서 색상 선택기를 제거하고 설정 탭 맨 아래에 유지한다.
- 이후 화면은 주간 블루를 기준으로 만들며 다른 4개 팔레트로 전환 가능하게 설계한다.
- 다음 개선 화면 순서를 논의하고 현재 시간 구간을 설명한다.

구현
- 1/3 debug 선택기 및 전용 import/kDebugMode 분기 제거.
- 메인 SettingsTab 마지막 항목에 기존 공통 AppUiThemePreview 배치.
  debug 전용 제한 없이 표시한다. 부가 기능/백업 하위 설정에는 중복 표시하지 않는다.
- Align 전체 폭 항목으로 설정 목록의 가장 마지막 줄을 사용한다.
  휴대폰 한 열 및 넓은 화면 두 열 모두 마지막 항목으로 접근 가능.
- 선택기 자체에 AppUiThemeScope를 적용해 현재 자동/고정 테마와 대비를 반영한다.
  설정 탭 기존 전체 레이아웃/화면의 테마 중앙화는 이번 작업에 포함하지 않는다.
- 자동/고정 preference 저장 키는 그대로 유지. 기존 선택도 이어진다.
- 공통 선택기 key는 app-ui-theme-*로 정리한다.
