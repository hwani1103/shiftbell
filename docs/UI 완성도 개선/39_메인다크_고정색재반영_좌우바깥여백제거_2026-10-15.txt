사용자 지시
- 메인 다크는 화면 색상과 관계없이 기존 다크 배색으로 고정.
- 기기에서 화면 색상 흰색 선택 시 달력도 흰색으로 보인다고 지적함.
- 다크로 복귀한 것을 사용자가 확인한 뒤, 이 상태에서 달력 바깥 앱 패딩을 없애고 핫리로드하도록 지시함.

조사와 재반영
- dev 기기 SM-S948N, 프로세스 3907에서 calendar_theme_id=mainDark, app_ui_preview_theme=originalWhite 저장 상태와 흰 달력 화면을 확인함.
- 소스에는 UI36의 프레임/읽기 팔레트 제외 규칙이 있었으나 실제 기기 화면과 불일치함. 소스만으로 고정 상태라고 단정했던 설명을 정정함.
- 임시 진단을 추가한 첫 재로드에서 NoSuchMethodError: preservesOriginalAppearance가 발생함. 실행 중인 라이브러리에 새 정적 메서드가 반영되지 않은 상태라는 증거이며, 최초 누락 경위는 확정하지 않음.
- CalendarThemeRollout의 고정 배색 규칙을 다시 컴파일하여 11/2160 라이브러리, 2684ms 핫리로드 성공. 사용자 “오케이 돌아왔다” 확인 및 reloaded.png에서 다크 배경/흰 글자 확인.
- 임시 진단 로그는 삭제. 저장된 화면 색상이나 달력 선택을 강제로 바꾸지 않음.
