GAME-11 / 2026-10-15 / 독립 Sync Paths DEV

기준 및 사용자 최종 선택
GAME-10의 하단 버튼 선택 전용 조작을 기반으로 후속 수정한다. 이전 원장과 APK는 당시 증거로 보존한다.
게임 이름은 사용자가 선택한 Sync Paths. Path Pals는 채택하지 않은 초기 제안이다.
12번 UI 대기 항목과 후속 완료 연결을 기존 작업에서 확인했으며 이번은 독립 게임 범위다.

시작 흐름
- 앱 실행 시 Sync Paths 이름이 포함된 정면 격자 만화 포스터를 한 번 표시한다.
- 포스터 디코딩 준비 후 약 1.4초 뒤 레벨 목록으로 자동 전환한다. 별도 시작/이어하기 버튼이나 화면 첫 진입 도움말은 없다.
- 목록 복귀/앱 일시 중단 복귀 때 포스터를 재생하지 않는다. 새로운 앱 실행은 다시 표시한다.
- Android 시작 창은 같은 연한 배경으로 맞추고 Android 12 이상의 기본 아이콘 표시를 투명 리소스로 대체한다. 별도의 두 번째 포스터는 추가하지 않았다.
- 도움말은 기존 게임 진입 후 안내와 게임 메뉴에 유지한다.

이미지
- built-in image_gen 사용. 사용자 피드백 이후 재생성은 한 번만 수행했다.
- 대각선/원근 타일과 굵은 색 띠를 제외했다. 가는 직각 경로, 네 공의 서로 다른 표정, 충돌을 피해 별까지 이동하는 개념을 중심으로 구성했다.
- 열쇠/문/포탈을 강조하지 않았다. 게임 이름을 이미지 상단에 포함했다.
- 최종 자산: examples/sync_path_lab/assets/art/sync_paths_splash.webp
- RGB 512x768, WebP quality 72 / method 6, 20,584바이트(약20KB). 원본 PNG는 증거 폴더에만 보관하고 앱에 넣지 않는다.
- 전체 프롬프트와 압축 조건: GAME-11_검증_2026-10-15/image-prompt.txt.
- 초기 Path Pals 포스터는 폐기 후보로 증거 폴더에만 보존하며 앱 자산에서 제외했다.

레벨 목록
- 맨 위 LV100, 맨 아래 LV1의 내림차순. 신규 진행의 첫 화면은 LV1이 보이도록 맨 아래에 위치한다.
- 기존 마지막으로 연 레벨 복귀/저장 규칙은 유지한다. 저장이 있는 사용자는 마지막 레벨 위치로 돌아간다.
- 시작하기/이어하기/같은 칸당 속도 소개 문구를 목록에서 제거했다. 레벨 카드를 직접 탭해 시작한다.
- 이름을 앱 제목/웹 메타/독립 Android 표시 이름에 연결하되 앱 ID와 저장 키는 유지했다.

선택과 게임 화면
- 레벨 진입/다시 시작은 첫 번째 파란 공을 선택한다.
- 현재 선택된 하단 공 버튼을 탭하면 선택 없음. 그 뒤 같은 공 또는 다른 공 버튼을 탭하면 해당 공을 선택한다.
- 현재 경로가 별에 닿으면 다음 미완성 공을 순서대로 선택한다. 이미 완성된 공은 건너뛰며 마지막 공까지 완성되면 마지막 선택을 유지한다.
- 보드는 계속 경로 입력 전용이다. 공 중앙/출발 칸 재방문도 그대로 입력한다.
- 되돌리기는 기존 선택된 공의 경로를 한 단계 되돌리는 동작을 유지한다. 자동 전환 전 공을 수정하려면 해당 공 버튼으로 다시 고른다.
- '함께 출발'을 '출발'(영문 Go)로 변경했다.
- 되돌리기는 글자 없이 아이콘만 있는 OutlinedButton. 출발과 같은 48px 최소 높이, 가로 비율 3:7(버튼 사이 공통 여백 제외).
- 게임 헤더 LV 카드는 88x36 공통 토큰을 사용한다. LV100까지 고정 크기로 수용하며 CampaignColors.card/ink를 목록과 공용으로 사용한다.
- 기존 시간 점/금색·파란색 문/축소 공 그림/포탈 IN·OUT을 유지한다. 레벨/이동·충돌·시간/하트 규칙은 변경하지 않았다.
