## 수정 근거와 계약

1. 전체화면 하단 버튼/설명: edge-to-edge 상태에서 실제 systemBars/displayCutout inset을 root padding에 반영. 반응형 계산도 안전 영역을 제외한 가용 높이를 쓴다. 장식만 축소하고 48dp 제어 영역은 유지한다.
2. 알림 본문을 눌러 Activity로 이동할 때 외부 overlay가 남는 문제: 같은 (alarmId, round)의 overlay 창과 service-local 타이머만 해제한다. RingingAlarmTracker, AlarmPlayer, 독립 회차 마감은 유지한다. 오래된 회차의 요청은 현재 창을 제거하지 않는다.
3. 첫 숫자/언어 갱신의 삼성 자동 접힘: 일반 울림 알림에서 초기/갱신 모두 setSilent(false), GROUP_ALERT_ALL, ONLY_ALERT_ONCE를 유지한다. 기존 코드의 setSilent(true)는 AndroidX 1.17.0에서 groupAlertBehavior를 바꿨다. 기존 그룹·채널을 보존하고 갱신으로 분류가 바뀌지 않게 한다.
4. 삼성 시스템 알림 스누즈가 다음 울림까지 숨기는 문제: ID 7777에 회차별 tag `shiftbell:ring:<alarmId>:<round>`를 추가한다. 같은 회차는 같은 key로 갱신하고 다음 회차는 다른 OS key를 쓴다. 마지막 게시 tag/id/round는 DPS ring_notice에 저장해 process death 뒤 숨겨진 알림도 종료 시 취소한다. 기존 untagged 7777은 새 울림 최초 게시 전에 정리한다.

### FSI 갱신 계약의 변경

B 설계의 “갱신 시 fullScreenIntent 필드를 제거”는 삼성에서 분류/확장 상태 변화와 시스템 스누즈 노출을 일으켰다. C는 최초 FSI 전용 PendingIntent와 사용자의 본문 탭 PendingIntent를 분리한다. 최초 FSI는 회차 URI `/initial-fsi` + ONE_SHOT/IMMUTABLE이며 최초 게시에서만 생성한다. Activity/외부 overlay/앱 내부 카드가 표시되거나 사용자가 실제 조절하면 cancel()로 실행 권한을 폐기한다. 갱신에는 그 **같은 폐기된 토큰**만 보존한다. 본문 탭 `/screen`은 별도 토큰이라 계속 정상 동작한다. 숫자/언어 갱신은 새 FSI 토큰을 생성하지 않는다. 커버 진입은 LOW/STATUS로 기존처럼 바꾸고 폐기된 FSI 토큰만 유지한다. 커버에서 일반 화면으로 채널을 되돌리는 재게시에는 사용자 지정 채널 소리가 재생되지 않도록 quietAfterCover를 유지한다. 해당 회차의 이후 갱신도 같은 quiet 분류를 유지한다. 일반 최초 울림의 GROUP_ALERT_ALL 정책과 이 표시 인계 분기는 구분한다.

이는 AOSP 템플릿이 fullScreenIntent 존재 여부로 시스템 snooze 버튼 노출을 결정하는 동작과 삼성 실측을 함께 고려한 변경이다. 공용 API로 시스템 스누즈를 전역 차단하거나 OEM 동작을 보장한다고 해석하지 않는다. 회차별 key 분리는 OEM이 시스템 스누즈를 다른 경로로 허용할 때도 다음 알람을 보호하는 별도 방어다.

근거: [AOSP Notification 템플릿의 bindSnoozeAction](https://android.googlesource.com/platform/frameworks/base/+/90390f08148d93e1248a59e164ca32259608a0ff/core/java/android/app/Notification.java). 삼성에서 실제 버튼 부재·확장 유지·Activity 재실행 부재는 C 기기 시험으로 따로 판정한다.
