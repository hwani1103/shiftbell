7. 온보딩 권한 연결
   미허용/확인 불가 카드만 보여주고 개별 설정 버튼을 유지. 누른 카드부터 설정.
   실제 granted를 다시 읽었을 때만 다음 denied 권한으로 이어짐. 우선순위는 알림→오버레이→정확한 알람→전체화면→별도 알람 채널.
   설정 이동 성공이나 요청 콜백만으로 허용 판정하지 않음. 거절·취소·확인 불가·해당 없음은 그 요청의 자동 연결을 중단.
   runtime 알림 요청은 사용자 응답 콜백을, 외부 설정은 앱 resumed를 기준으로 완료 후 재조회.
   백그라운드에서는 다음 설정을 열지 않음. 중복 요청/늦은 읽기/숨겨진 라우트/폐기된 화면은 방어.
   일반 설정·도움말은 수동 개별 설정 유지. Xiaomi 제조사 안내는 읽기만으로 완료 판정하지 않음.
   10/9 후속 사용자 요청이 과거 '연쇄 실행하지 않음' 정책을 온보딩의 실제 허용 확인 성공에 한해 변경함.
   P0 실행기에 새 권한 연결·온보딩 복귀 회귀 테스트 포함.
