1. 연결 순서와 현재 범위
Fold8 → Fold8 Ultra → Flip8. 기기별 2시간 연결 계획. 예약 연장 승인으로 해석하지 않는다.
Fold8은 추가 스토어 펼침 달력 촬영을 먼저 확보한 뒤 기존 잔여 UI 검사를 한다.
달력 제품 레이아웃/디자인 수정은 하지 않는다. Fold8 한글/영어 확정 레이아웃을 보호한다.
검사 초점: 버튼 탭 후 팝업/설정 하위 화면/전체근무표, 아이콘·글꼴 정렬, 긴 근무명 말줄임·잘림·깨짐, 선택 언어와 다른 언어 혼입, 도움말·개인정보의 해당 언어 제공 기능 일치.
기존 기능 전수검사는 반복하지 않는다. UI/공통 코드 수정에 필요한 회귀만 시행한다.
Flip8 공통 커버 최초 크기/측정 변경 후 실제 커버 재검증은 유지한다.
Flip4 커버는 완료 보존. 본화면 전수검사는 사용자 결정으로 현재 범위에서 제외하고 Flip8을 대표 기기로 검사한다. 과거 본화면 NOT_RUN과 세 연결의 정리 UNCONFIRMED는 PASS로 바꾸지 않는다.
근거: 실제 Flip4 본화면1080×2640/480dpi(360×880dp 전체), Flip8 본화면1080×2520(360×840dp 전체). 가로폭 같음/세로40dp 차이. 커버512×260 대948×1048은 별도 조건이다.

2. 스토어 산출물
사용자 저장 대상: C:\Users\Administrator\Desktop\PlayStore 등록정보 Folder
기존 촬영안내.txt는 보존한다. ko-KR/en-US/hi-IN/pt-BR/de-DE 언어별 폴더로 구분한다.
사용자 최종 정정: 언어별 화면 이미지5장 + 메인 홍보이미지1장 =6장.
화면5종: S26 Ultra 잠금 알람, 전체 조 근무표, 메인 달력, OT입력/주별근무시간 상하 합성1장, Fold8 펼침 달력.
OT/주별근무시간은 각각 원본1장씩 확보해 최종1장으로 구성한다. 전체 원본은 언어별6장이고 최종 등록용 화면은5장이다.
S26 Ultra 데이터는 사용자가 준비한다. 테마는 사용자 지정 대기. 특히 OT/주별근무시간 촬영 직전에 사용자에게 준비 완료를 확인한다.
메인 홍보이미지는 실제 화면 원본 확보 후 구성한다. 앱 화면을 AI로 재제작하지 않는다.

3. Fold8 촬영 장면
실제 온보딩에서 패턴을 만든다. 한 패턴에 휴무 종류는1개, 근무일4개, 각 구간은2일 단위.
예정 패턴: 주간·주간·휴무·휴무·야간·야간·휴무·휴무(8일 순환). 근무명을 단일 문자로 축약하지 않는다.
한국어 심플라인(minimal), 영어 Periwinkle(periwinkle)는 사용자 지정 확정.
독일어/브라질 포르투갈어/힌디어는 Periwinkle 예정이며 사용자 테마 답은 아직 미확보다.
기존 테마 팔레트를 보호하면서 주간/야간/휴무 색을 구분한다. 한 달의5날짜에 러닝·저녁약속·병원·은행·장보기 같은 짧은 노트식 현지어 메모를 넣는다.
2026년10월5/10/15/20/25일을 준비용 날짜로 잡았다. 실제 촬영 전에 월/패턴 시작점/메모 배치와 잘림 여부를 확인한다.
한 언어의 지정 테마에서 촬영1회씩, 총5장 펼침 달력 원본. 여러 테마 전수 촬영이나 기존 접힘 캡처 반복은 하지 않는다.
옛 tools/capture_playstore_fold8.py는 접힘/메모없음/DB직접seed라 이번 요구와 다르다. 그대로 실행하지 않는다.
