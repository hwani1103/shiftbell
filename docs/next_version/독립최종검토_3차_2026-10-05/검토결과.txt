네 언어 전체 3차 독립 최종 텍스트 검토 — 2026-10-05

판정
지정 리소스의 텍스트 검토와 발견한 첫 출시 범위 문구 결함 수정은 완료했다.
현재 발견한 텍스트 차단 문제는 없으며 이 문구를 다음 검증의 고정 기준으로 사용할 수 있다.
실기기 비노출/현지 사용자 이해도/레이아웃까지 포함한 출시 최종 승인 또는 100% 무결함 판정은 아니다.

범위와 순서
브라질 포르투갈어 → 독일어 → 영어 → 힌디어.
각 언어 ARB 681개 + Android 문자열 48개 + 요일 배열 항목 7개 = 736개, 총 2,944개 독해·판정.
1차 의미카드와 용어 기준을 사용해 T01~T07 후보를 먼저 기록한 다음 상세 변경 사유를 대조했다. 이전 요약을 보았으므로 완전 블라인드/다른 사람의 감수라고 표현하지 않는다.
처음 요청된 레이아웃 검증 제외 지시를 유지했다. 캡처·기기 설치·글자 배율·접힘 검사는 수행하지 않았다.

최종 변경
pt-BR 17개, de-DE 17개, en 15개, hi-IN 16개 = 65개. 유지 2,879개.
- 실제 단수 도달 조건 보완: 5개.
- 날짜별 팀 근무 제목: 4개.
- 스누즈 충돌 결과 설명: 4개.
- 외국어 첫 출시의 제공 기능만 설명: 52개(13키 × 4언어).
Android 네 언어 문자열 파일은 이번 시작 스냅샷과 동일하다. 이전 1·2차의 수정은 보존했다.
키 추가/삭제·한국어 ARB 수정 없음. 한국어 기능명과 데이터 저장/삭제 동작은 유지했다.

미제공 기능 점검
개인 일정, 수면·회복 전체, 앱 안 친구 공유, 원터치 알람, 한국 공휴일/음력, 테마 4종, 한국어 문의 채널을 명시적으로 목록화했다.
개인정보처리방침·백업/진단 도움말·초기화/알람 경고에서 “이전에 한국어로 이용한 경우” 등 관련 없는 설명을 제거했다. 데이터별 예외 안내를 넣지 않았다.
도움말 상세/검색 경유, 별도 공유 화면, 지연 튜토리얼, 초기화 실패 경고의 언어 제한을 보완했다.
수면 위젯 Manifest 기본 상태를 비활성으로 바꿔 첫 실행 전 노출 가능성을 차단했다. 한국어에서는 기존 언어 동기화 경로로 활성화한다.
세부 원인과 조치: 미제공_기능과_노출검증.txt. 관련 Dart 리소스 180키: 노출_검토원장.csv.

검증 결과
1) flutter gen-l10n 성공: 네 언어 ICU 생성.
2) Flutter 37개 통과: 기존 현지화 12개 + 이번 의미/비노출 회귀 25개.
   실제 단수 1/복수 2, 제공 기능 문구, 미제공 도움말 검색 제외, 상세/검색 경유 언어 재검사, 튜토리얼 차단, 테마 6종 제한.
3) Android ReleaseLanguagesTest 5개 통과: 실패/오류/건너뜀 0. 리소스 및 Kotlin 컴파일 성공.
   최초 수면 위젯 비활성, 한국어 활성, pt/de/en/hi 비활성 포함.
4) 리소스 구조 검사 오류 0: 키 누락, 인자 불일치, 한국어 잔존/깨진 문자, 대응 용어, 요일 배열.
5) 정적 분석 8개 파일: error/warning 0, info 71. 명령 자체는 info 때문에 비정상 종료이므로 “분석 전체 통과/무지적”으로 기록하지 않는다. 71건 모두 이번 수정 이전 HEAD와 동일한 코드 행에서 발생함을 정적분석_대조.json에 남겼다. 신규 변경 행의 지적 없음.
6) git diff --check 통과. 실제 변경 65건과 전수/변경 원장, 종료 리소스 해시 일치.
로그: gen_l10n.log, copy_and_exposure_tests.log, android_tests.log, android_test_results.xml, analyze.log, 리소스_검사.json.
Gradle의 기존 deprecation 경고는 테스트 실패가 아니며, 이번에 도구 버전을 변경하지 않았다. 최초 PowerShell wrapper 종료 코드와 BUILD SUCCESSFUL이 달라 동일 작업의 native exit code를 재확인했고 0이었다(android_exit_check.log).

남은 범위
- 네 언어 실기기 신규 설치에서 실제 메뉴·팝업·알림·위젯 선택기 비노출 확인. 특히 최초 앱 실행 전후 위젯 목록과 한국어 기존 위젯의 업데이트 후 활성화를 확인해야 한다. Robolectric 결과를 제조사 런처 실측으로 대체하지 않는다.
- 현지 교대근무자의 문구 이해도, 업종별 당직명, 힌디어 휴무/휴가 이해도 확인.
- 검증현황 7절의 전체 레이아웃은 전부 대기. 이 작업의 의미 위젯 테스트를 레이아웃 실적으로 넣지 않는다.
- 직접 참조가 없는 69키/언어는 정적 비참조로 기록했다. 현재 기능의 실제 화면을 봤다는 판정이 아니다.
- 수면 기능을 향후 번역 출시할 경우 T01 누락 문단·한국어 하드코딩·의료/법적 근거 원문을 별도 검토해야 한다. 이번 외국어 출시 문구 차단 사유로 오인하지 않는다.
- 별도 공개 웹 뷰어, 제3자 UI, 스토어 콘텐츠·콘솔·실제 네트워크 실측은 이번 승인 범위가 아니다.
