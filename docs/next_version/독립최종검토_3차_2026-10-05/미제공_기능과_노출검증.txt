네 언어 첫 출시 — 한국어 전용 기능 비노출 검증
기준: 2026-10-05, pt-BR → de-DE → en-US/en-GB → hi-IN.

최종 제품 기준
외국어 사용자가 아직 없다는 사용자 확인을 기준으로 신규 출시 내용을 제작한다.
외국어 사용자에게 한국어판에만 있는 기능이나 이전 한국어 사용 데이터를 설명하지 않는다.
기존 데이터 유무에 따라 한국어 기능을 소개하는 예외 화면/문단도 만들지 않는다.
언어는 국적이 아니라 앱의 활성 로케일로 판단한다. ko에서만 한국어 전용 기능을 제공한다.
한국어 원문·기능·저장 데이터를 삭제하거나 외국어 기능을 새로 활성화하는 작업이 아니다.

1. 한국어 전체판 중 네 언어에서 제공하지 않는 기능

F01 개인 일정관리: 일정 탭, 시간축 생성/편집, 시작·종료시간, 개인 일정 알림, 일정 내용 자동 아이콘 분류, 탭 재활성화 설정 및 최초 안내.
근거: main.dart _setupTabsAndPrewarm/_visibleTabIndices/_applyOpenDateSchedule; settings_tab.dart; onboarding_info_popups.dart; ScheduleNotificationScheduler/Receiver.
일반 근무표·근무 날짜 배정·메모는 별개의 제공 기능이므로 그대로 둔다.

F02 수면·회복 전체: 오늘의 컨디션/근무 연계 안내/관련 근거, 취침·기상 수동 기록, 자동 추정과 확인, 최근/전체 수면 기록, 근무별 수면 요약, 수면 위젯, 탭 재활성화 및 최초 안내.
근거: main.dart 한국어 탭/수면 prewarm 및 재개 조건; help_screen.dart 한국어 전용 두 섹션; SleepDetectionScheduler; SleepWidgetProvider/ActionReceiver; ReleaseLocalePolicy.
일반 근무 시작·종료시간 및 OT 집계는 제공 기능이므로 유지한다. 외국어에 수면 탭이 있다고 설명하지 않는다.

F03 앱 안 일정공유: 친구 목록/추가/삭제, 내 공유 코드와 이름, 공유 시작/중지, 공유 링크/코드 복사·전달, 친구 근무표 조회와 동기화 상태.
근거: calendar_tab.dart 공유 진입 차단; friend_list_screen.dart; my_share_code_screen.dart; friend_calendar_view.dart; FriendSyncService의 한국어 조건.
팀 전체 근무표는 사용자가 기기에서 만드는 별도 기능이며 친구 공유와 다르므로 제공한다.
한국어 사용자가 보낸 링크를 여는 별도 공개 웹 뷰어(web_main.dart)는 앱의 외국어 기능 진입이 아니다. 이번에 웹 게시·기능 변경·기기 검증을 수행하지 않았다.

F04 원터치 알람: 캘린더 상단 빠른 알람 패널, 프리셋 생성/편집/삭제, 오늘·내일 빠른 배정, 날짜 상세의 원터치 목록과 전용 삭제 안내.
근거: calendar_tab.dart usesKoreanFeatures 조건 및 quick panel 진입/언어 변경 닫힘; 날짜 상세 CustomAlarmDayList 조건.
근무별 알람 설정·알람 종료·5분 스누즈·이력은 제공 기능이므로 유지한다.
신규 외국어 설치에는 이 종류의 알람을 만드는 경로가 없다. 한국어 데이터 이관 예외 UI를 추가하지 않았다.

F05 한국 공휴일 및 한국 음력 표시: 앱 달력·위젯의 한국 공휴일 이름/표시, 음력 날짜, 한국 공휴일 Firebase 갱신.
근거: calendar_tab.dart 한국어 조건; holiday_sync_service.dart refreshIfDue; ReleaseLocalePolicy.isCalendarRedDay.
일요일 표시와 근무 일정·주간 집계는 제공 기능이다. 미제공 공휴일/음력을 비교 설명하는 문장은 외국어 도움말에서 제거했다.

F06 테마 4종: initialBadge(이니셜 뱃지), underline(언더라인), eventChip(이벤트 칩), editorial(매거진).
근거: calendar_theme.dart availableCalendarThemes/availableCalendarTheme; calendar_theme_picker_screen.dart.
외국어 제공 6종: mainWhite, mainDark, minimal, materialCard, diary, boldGrid.
테마 실험 위젯에 10종 구현이 남아 있어도 앱 선택기는 6종만 사용하고 미리보기를 IgnorePointer로 감싸므로 미제공 페이지로 직접 넘기는 기능은 없다. 10종 코드가 있다는 이유만으로 노출 결함으로 판정하지 않았다.

F07 한국어 문의 채널: 카카오톡/티스토리 안내. 외국어는 이메일 문의만 제공한다.
근거: 네 언어 privacyContactBody, 설정 문의 관련 현지화 문구. 한국어 경로를 외국어 안내에 추가하지 않는다.

2. 확인된 누락 원인과 조치

E01 상시 안내에 미제공 기능 설명 잔존
원인: 탭은 숨겨 놓았으나, 1·2차에서 모든 데이터 보존/공유 중지 의미를 설명하려고 외국어 개인정보처리방침·백업·삭제 경고에 한국어 전용 기능과 이전 이용 설명을 유지했다.
조치: 네 언어의 초기화/전체 알람 삭제/근무 변경, 개인정보 요약/로컬 저장/Google 섹션/보관, 백업/진단/달력/위젯 도움말을 제공 기능만 설명하도록 분리했다. 공유 섹션은 실제 쓰는 Google Play 업데이트 확인만 남겼다. 분석·광고·권한·비암호화 백업·수동 파일 전송 설명은 보존한다.
기존 결정과 차이: 유지에서 수정으로 변경. 근거는 최신 사용자 지시와 실제 언어별 제공 범위이며, 표현 취향이 아니다. 중간에 제안한 “이전에 한국어로 사용한 경우” 12개 문구는 철회했고 조건부 예외 문단도 넣지 않았다.

E02 초기화 실패 경고가 외국어에도 공유를 설명할 수 있음
원인: 초기화 결과의 sharingStopSaved 실패를 언어와 무관하게 snackbar로 표시.
조치: settings_tab.dart에서 한국어에만 이 공유 경고를 표시한다. 정상 초기화·로컬 삭제·기존 공유 중지 처리 자체는 변경하지 않는다.

E03 도움말 상세가 섹션의 한국어 제한을 잃음
원인: 목차는 필터하지만 상세 route에 section.koreanOnly가 전달되지 않음. 검색 결과 섹션 생성도 이 플래그를 생략함.
조치: 검색·목차·상세에 플래그를 전달하고 상세 build에서 활성 언어를 재검사한다. 외국어이면 제공 도움말 목록을 표시한다.
검사: 네 언어에서 숨김 항목 검색 제외, 이미 열린 상세 비노출, 한국어 검색으로 연 상세의 언어 변경 후 비노출을 의미 위젯 테스트로 확인. 캡처·레이아웃 검사가 아니다.

E04 별도 공유 화면/지연 팝업의 언어 재검사 없음
원인: 진입점의 언어 제한에만 의존하므로 열린 route나 예약된 안내가 언어 변경 뒤 남을 수 있음.
조치: 앱 안 친구 목록/내 공유코드/친구 근무표 build에서 언어를 확인하고 미제공 기능명 없이 뒤로가기만 표시. 개인 일정·수면 튜토리얼은 호출 전/지연 후/표시 시 언어를 확인한다.
검사: 네 언어 직접 호출에서도 수면·개인 일정 튜토리얼이 열리지 않는 테스트 추가. 공유 서버에 접속하거나 타인에게 메시지를 전송하지 않았다.

E05 앱 첫 실행 전 수면 위젯이 선택기에 노출될 수 있음
원인: Manifest의 SleepWidgetProvider 기본 enabled=true. 외국어 비활성화는 앱 재개/언어 변경/업데이트 이후에야 실행됨.
조치: 기본 enabled=false로 변경. 한국어 앱 재개 또는 언어 변경/패키지 업데이트 시 기존 ReleaseLocalePolicy가 활성화한다. 한국어 신규 설치도 첫 실행 전에는 수면 위젯이 표시되지 않는다. 앱을 먼저 설정한 뒤 위젯을 추가한다.
검사: Robolectric에서 최초 receiver 비활성, 한국어 활성, 네 외국어 비활성 확인. 실제 제조사 런처 위젯 목록 및 한국어 기존 고정 위젯 업데이트는 실기기 미수행으로 남긴다.

E06 충돌 안내에 원터치 기능명 노출
조치: fixedAlarmSkippedByOneTap의 외국어 문구를 “같은 시각에 다른 알람이 먼저 있어서 근무 알람을 건너뜀”으로 변경. 키와 충돌 동작·날짜 인자는 그대로다. 기능명 없이 실제 결과를 전달한다.

3. 유지한 경로와 기록
Android sleep_widget_*, app_widget_sleep_label, sleep_widget_description는 번역 리소스로 남지만 비활성 receiver에 연결된다.
channel_schedule_notify는 개인 일정 알림 채널이다. 외국어에서 scheduler/receiver가 알림 생성 전에 막으므로 신규 설치에서 생성하지 않는다.
one_tap_alarm_label은 원터치 알람 전용 원시 리소스다. 외국어에서 원터치 생성 UI가 없으며 새로 활성화하지 않았다.
관련 Dart 리소스 180키의 위치·판정은 노출_검토원장.csv에 기록했다. 키워드 후보의 오탐(일반 알람/메모/복원 등)도 삭제하지 않고 유지 이유를 남겼다.
현재 직접 참조가 없는 ARB는 언어당 69키다. 2차의 70키에서 이번 commonClose 사용이 추가되어 69가 되었다. 직접호출_미발견.csv는 정적 비참조 목록이며 화면 실측 완료 목록이 아니다.

4. 완료와 미수행 구분
완료: 지정 네 언어 리소스 독해, 기능 범위 목록, 앱 코드의 진입/도움말/문구/알림/위젯 분기 점검, 확인된 결함 수정, 명시한 자동 회귀 검사.
미수행: 실제 기기/제조사 런처에서 신규 설치·첫 실행 전후·언어별 접근을 직접 조작하는 노출 검사, 실제 알람 울림, 현지 사용자 이해도 검사.
레이아웃: 사용자 요청으로 전부 미수행. 이번 의미 위젯 테스트를 화면 폭·글자 배율·접힘 검증으로 계산하지 않는다.
현재 발견한 외국어 첫 출시 문구 노출 결함은 수정했다. 이를 실기기까지 100% 무결함이라는 판정으로 확대하지 않는다.
