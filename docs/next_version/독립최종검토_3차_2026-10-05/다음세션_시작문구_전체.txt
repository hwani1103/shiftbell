외국어판은 아직 설치자가 없는 첫 출시다. 외국어 사용자는 자기에게 제공되는 내용만 보게 하고, “이전에 한국어로 사용했다면” 같은 안내나 데이터별 예외는 두지 마. 한국어 기능과 필요한 한국어 문구·사용자 데이터는 보존해.

1. 기존 완료 판정을 그대로 믿지 말고 현재 전체 Flutter/Android 리소스와 사용자 노출 하드코딩 문구를 실제 코드·한국어 기능 의미와 대조해. 브라질 포르투갈어 → 독일어 → 영어 → 힌디어 순서로 기능 의미, 버튼·도움말 일관성, 누락·변수·복수형, 1·2·3차 수정으로 생긴 회귀를 확인해. 수정 후보를 먼저 기록하고 기존 상세 변경 사유와 비교해.

2. 한국어에는 제공하지만 네 외국어에는 제공하지 않는 기능을 실제 코드로 확정하고 목록화해. 현재 개인 일정관리, 수면·회복과 수면 위젯, 앱 안 친구 공유, 원터치 알람, 한국 공휴일·음력, 달력 테마 4종, 한국어 문의 채널이 대상이야. 원터치 알람 미제공과 Firebase 한국 공휴일 자동 조회·갱신 차단도 재확인해.

3. 외국어 사용자에게 노출될 일이 없는 문구를 전수 조사하고 불필요한 외국어 번역을 삭제해. 키 이름이나 직접 호출 검색만으로 판단하지 말고 호출 위치·조건·진입점·언어 제한·신규 설치에서의 도달 가능성을 추적해. 버튼·메뉴·도움말 목록/검색/상세·개인정보처리방침·팝업·상태/실패 안내·알림·위젯·테마 미리보기를 모두 포함해. 사용 경로가 미확인인 것은 조사 완료나 삭제 확정으로 처리하지 마.

4. fixedAlarmSkippedByOneTap부터 유사 항목을 전부 조사해. 3차에서 원터치 충돌 안내를 “다른 알람”으로 일반화한 외국어 수정 4건은 불필요하다고 지적했지만 현재 파일과 원장에는 아직 남아 있어. 해당 표시 코드는 언어로 직접 차단된 것이 아니라 원터치 알람이 없는 외국어 신규 사용에서 조건이 발생하지 않는 구조였어. 이 구분을 명확히 하고, 관련 없는 기능 설명을 일반화해 새로 만들거나 유지하지 마.

5. 한국어에 필요한 문구는 한국어 전용 리소스로 분리하는 등 필요한 구조를 정리해. 외국어 ARB에서 키만 삭제하고 한국어가 자동 대체되는 상태로 끝내지 마. 생성 코드, 누락 번역 보고, 언어 fallback, Android 기본 리소스 대체, 공통 컴포넌트와 별도 공개 웹 뷰어 의존성까지 확인해. 빈 문자열로 숨기거나 키 일치 검사를 무작정 무력화하지 마. 필요한 검사도 실제 기능별 리소스 범위에 맞게 정리해.

6. 스케줄 초기화처럼 외국어에 제공되는 버튼·경고·도움말 등에 한국어 전용 기능 설명이 섞인 경우를 전수 조사하고 한국어/외국어로 분기해. 초기화, 전체 알람 삭제, 근무 변경, 백업·복원, 실패 안내를 특히 확인해. 외국어는 제공되는 기능과 실제 결과만 설명하게 해. 미제공 기능의 도달 가능한 호출은 외국어에서 차단하고 별도 진입·열린 화면·지연 팝업의 언어 변경도 확인해.

7. 삭제·분기 후 생성·빌드·관련 회귀 검사를 실행해서 필요한 번역 누락, 한국어 fallback 노출, 한국어 기능 손상, 제공 기능 설명 누락, 변수·복수형 불일치가 없는지 확인해. 실기기 확인과 정적 추적·자동 검사를 구별하고 미검증 범위는 완료로 표시하지 마. 취향 차이만으로 문구를 바꾸지 마.

8. 언어·리소스·키/코드 위치·변경 전후·출처·호출/도달 근거·기존 결정과의 차이·삭제/분기/유지 이유를 후속 원장에 남겨. 1·2·3차 기록과 기존 미커밋 변경을 보존하고 후속 판정으로 연결해. 종료할 때 검증현황과 다음 시작점을 갱신하고 삭제/수정/유지 건수, 문구 확정 가능 여부, 남은 문제를 알려줘.
