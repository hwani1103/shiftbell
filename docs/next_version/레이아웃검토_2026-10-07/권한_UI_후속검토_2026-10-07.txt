알람 권한 설정 UI 후속 검토 (2026-10-07)

요청 범위
- 설정의 다른 목록 항목과 레이아웃을 맞추고, 권한 화면의 목적과 안내 문구를 점검한다.
- 한국어 권한 안내의 ShiftBell 표기를 교대시계 앱으로 변경한다.
- 권한 판정, 시스템 설정 이동, 설정 복귀 및 알람 기능 로직은 변경하지 않는다.

존재 목적과 위치 판단
- settings_tab.dart의 항목은 showPermissionSettings → PermissionPanel을 연다.
- PermissionController가 알림, 다른 앱 위에 표시, 정확한 알람, 잠금화면 표시 상태를 조회한다.
  초기 안내에서 빠진 권한이나 나중에 변경된 권한을 다시 확인·설정하는 진입점이다.
- 앱 전체 알림/알람 채널 차단 안내와 잠금화면 문제 해결 도움말도 연결되어 있다.
- 설정에서 제거하지 않고 기존 도움말 그룹의 첫 항목에 유지한다. 설정 복구·문제 해결 목적과 맞는다.
  맨 위 알람음 관리/근무시간 항목의 기존 위치도 유지한다.

기존 안내의 문제
- 권한이 허용되면 각 권한 설명이 숨겨져 화면 전체의 목적을 이해하기 어려웠다.
- 다른 앱 위에 표시의 앱 선택 안내가 전체 화면 하단에 항상 나와 특정 권한 전용 화면처럼 보였다.
- 설정 목록 항목에는 주변 항목과 달리 목적 설명과 이동 화살표가 없었다.

변경
- 설정 목록에 테마 대응 아이콘 색, 목적 설명, 이동 화살표를 추가했다.
- 시트에 제목/설명/핸들을 추가하고 네 권한을 같은 카드 구조로 정리했다.
  허용 여부와 관계없이 각 권한의 용도를 표시하고, 상태는 별도 줄에 유지한다.
- 다른 앱 위에 표시의 앱 선택 안내는 해당 권한에 설정이 필요할 때 그 카드 안에서만 표시한다.
- 하단에는 모든 권한에 공통인 시스템 설정에서 앱으로 돌아오는 안내를 둔다.
- 한국어 권한 안내와 연결 도움말의 앱 표기를 교대시계 앱으로 바꿨다.
  Download/ShiftBell 같은 실제 파일 경로와 백업 파일명은 유지한다.
- 잠금화면 설명은 사용 목적을 설명하는 문장으로 바꿔 이미 허용된 상태에서 허용을 재촉하지 않는다.
- 공통 목적 설명 키는 ko/en/de/pt/hi 다섯 ARB에 추가하고 생성기로 갱신했다.
  한국어 전용 기능 리소스와 common 리소스의 구조/기능 범위는 유지했다.

기능 보존
- PermissionService/PermissionController/native 권한 코드는 변경하지 않았다.
- granted/denied/unknown/notApplicable 구분, 알람 채널 차단 구분, 중복 설정 열기 방지,
  resume 후 상태 재조회와 OEM 도움말 버튼의 동작을 유지한다.
- USB에서는 권한 목록만 열어 확인했으며 시스템 권한 변경 버튼은 누르지 않았다.
