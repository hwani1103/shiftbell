지역 날짜·요일·OT 수정 후속 검토 — 2026-10-06

범위
국가관습_재점검_2026-10-06의 C01~C03을 사용자 요청으로 실제 수정했다.
수정 전 후보는 수정후보.txt, 변경 전후와 상세 사유는 후속_수정원장.csv에 연결했다.
이전 1·2·3차, 후속, 최종튜닝, 국가관습 조사 기록을 보존한다. 이전 조사 프로브는
당시 결함을 관찰하는 증거이므로 수정 후 정상값에 맞춰 역으로 고치지 않았다.

C01 공개 웹
friend_web_calendar의 한국어 외 en_US 고정을 제거했다. 현재 resolved locale와
Material 주 시작 정책을 사용한다. 동일 위젯을 유지한 언어 변경에서도 독일어,
pt-BR, 힌디어 요일을 표시하고 영국·독일·UAE는 월요일부터 표시한다.
사용자가 작성한 이름·근무표를 번역하거나 지우지 않는다.

C02 근무시간·OT
현지 시각에 24시간씩 더하던 순회를 연/월/일 필드 기반으로 교체했다.
UTC는 날짜 계산을 위한 내부 표현이며 실제 instant를 UTC로 바꾸는 변환이 아니다.
월 총 근무시간, 주별 요약, OT 목록, 월을 덮는 주 범위, OT 캐시 갱신/기간 조회,
달력 앞뒤 캐시 조회 기간을 함께 확인했다. 날짜 반환은 기존 local 날짜 계약을 유지한다.
서머타임 봄/가을 및 30분 전환에서도 끝날 포함 각 날짜를 정확히 한 번 집계한다.
DB에서 0으로 삭제된 OT가 캐시에 남거나 범위 밖 OT를 지우는지도 임시 DB로 검사했다.

한국 보존
한국은 서머타임을 사용하지 않는다. 이번 변경은 한국에 DST를 적용하는 기능이 아니다.
한국 호스트의 1월/7월 +09:00을 확인하고 수정 전 계산기와 수정 후 계산기를 대조했다.
2024/2026/2027/2028년 매월, 규칙/불규칙, 월 단위/급여기간/주별 기간,
수동 OT·근무변경 OT 켬/끔을 조합한 3,492개 비교가 모두 일치했다.
합계·날짜별 목록·근무일 수·분 수·주 범위·입력 데이터 불변을 확인했다.
기존 총 근무시간 = 실제 배정 근무시간 + 수동 OT를 유지한다.
근무변경으로 늘어난 시간은 옵션을 켰을 때 OT 표시에만 더하며 총 근무시간에
이중으로 더하지 않는다. 줄어든 근무는 음수 근무변경 OT로 만들지 않는다.
근무당 사용자가 정한 분 수를 합산하는 기존 의미이며 실제 출퇴근 경과시간 계산이나
법정 초과근무 판정으로 바꾸지 않았다. 저장 형식·입력 단위·DB 마이그레이션 변경 없음.

C03 영어 지역 보존
en-US/GB에 더해 ZA/IN/AE/PH의 지역 정보를 보존한다. 미지원 우선 언어에서 영어로
fallback할 때도 출시 지역을 유지하며 차선 한국어로 되돌리지 않는다.
기존 한국어·독일어·pt-BR·힌디어 우선 분기는 유지했다.
현재 Flutter/Intl 데이터를 공식 CLDR와 대조했다(국가관습 폴더 출처.txt S01/S08).
남아공: 2026/04/05, 일요일 시작. 인도 영어: 5/4/2026, 일요일 시작.
UAE 영어: 4/5/2026, 월요일 시작. 아랍어 날짜 형식을 영어 UI에 임의 적용하지 않았다.
Intl에 없는 en_AE는 좁은 Material delegate로 주 시작을 보완했다. 남아공의 실제
날짜 입력 parser/formatter와 맞지 않던 hint도 yyyy/mm/dd로 맞췄다.
앱·공개 웹에 같은 delegate를 등록하고 native 위젯 정책에도 UAE 월요일을 반영했다.
표시 순서를 바꿔도 저장 요일 인덱스·알람 반복요일 의미는 바뀌지 않는다.

유지한 범위
해외 공휴일은 첫 버전에 추가하지 않는다. 한국어 공휴일 기능은 보존했다.
달력의 주 시작과 월~일 근무시간 집계 주는 별개다. 새 집계 주 설정은 이번에 추가하지 않았다.
알람 목록 24시간/입력 기기 설정이라는 기존 정책과 도움말을 유지했다.
알람 DST resolver 자체는 이번 변경 대상이 아니다. 기존 Dart/native의 없는 시각,
겹치는 시각, 충돌 제거, 실제 경과시간 스누즈 검사를 필수 실행기에 포함했다.
공통 ARB/native 번역 문구를 취향으로 바꾸거나 한국어 fallback에 의존하지 않았다.

검증의 한계
시간대 검사는 IANA timezone 객체를 실제 집계 함수에 전달하는 호스트 검사다.
한국 원본 비교도 호스트 검사다. 기기의 OS 시간대를 바꾸거나 실기기에서 DST 전환을
관찰한 결과가 아니다. Windows TZ 환경변수 탐색은 DST 실측 근거로 사용하지 않았다.
권한·잠금 알람·제조사 설정·실서버·브라우저 설치 등 기존 실기기 미검증을 승격하지 않는다.
