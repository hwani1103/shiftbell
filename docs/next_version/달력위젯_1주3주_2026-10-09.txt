달력 위젯 1주·3주 개선 — U01 후속 (2026-10-09)

요청 범위
- 기존 달력 위젯을 개선하고 같은 스타일의 이번 주 1주 위젯을 추가. 수면 위젯은 변경하지 않음.
- 사용자 후속 지시: 근무명 길이에 상관없이 셀 간격 동일. 근무명 끝 생략 금지, 전체 이름을 글자 크기로 맞춤. 위아래 여백 압축.

기존 구조 조사
- CalendarWidgetProvider: DB 직접 읽기, Flutter 저장 직후 refreshCalendarWidget, AlarmGuardReceiver 하트비트, 30분 AppWidget backstop.
- 400dp 이상이면 6주로 전환하던 분기와 calendar_widget_full.xml 제거.
- schedule_provider/memo_provider/holiday_sync_service/restore_coordinator의 기존 즉시 갱신 호출 보존.
- ReleaseLocalePolicy: 한국어에만 SleepWidgetProvider enabled. 외국어에서는 disabled. 기존 한국어 pinned 수면 위젯의 외국어 전환 제거/한국어 수동 재추가 계약 그대로.

구현
- 기존 CalendarWidgetProvider component 유지. WeekCalendarWidgetProvider 추가. requestUpdate가 두 provider ID를 모두 갱신하며, 1주만 설치된 경우도 갱신.
- 3주: 현지화된 오늘 날짜 제목 + 낮/밤 아이콘 + 전주/이번 주/다음 주. 1주: 요일 헤더 + 이번 주만. 음력·공휴일 이름 없음.
- 9국가 KR/US/GB/ZA/AE/PH/BR/DE/IN의 기존 ReleaseLocalePolicy/NationalHolidayDates/한국 휴일 override 사용. 휴일 데이터나 국가 정책 자체를 수정하지 않음.
- 낮 06:00~17:59는 옅은 그린 #F0F6F1, 나머지는 옅은 인디고 #EEF0FA. 기기 현지 시간대 기준, DST·여행에 따라 재평가. 국가당 하나의 고정 시간대를 가정하지 않음. 날씨·천문 일출/일몰 정보 아님.
- 정확 알람·새 백그라운드 작업 없음. 기존 시간/시간대 변경 및 guard/위젯 주기 갱신에서 재평가하므로 OS가 갱신을 지연하면 시간대 전환 표시도 늦을 수 있음.
- 기본 targetCellWidth=4. 가로만 리사이즈. minWidth=250dp. 카드 자체 높이는 3주262dp / 1주102dp로 제한; 런처가 큰 영역을 배정해도 내부가 늘어나지 않음. 홈 그리드 실제 점유 크기는 런처 기준.
- 셀 좌우 각1dp, 근무명 내부 각1dp 동일. 날짜16dp/근무명최대10dp/메모8dp. 글꼴 배율로 조밀한 격자가 깨지지 않게 고정 dp 사용.
- 근무명은 실제 locale 글꼴 폭으로 축소. 말줄임/고정 최소 크기 없음. 매우 긴 이름은 매우 작아짐. 접근성에는 전체 이름 유지. 공백 줄바꿈은 한 줄 공백으로 정규화.
- Android31+ host sizes의 RemoteViews를 만들고, 이전 host에는 가로/세로 폭별 RemoteViews 제공. 같은 업데이트의 색상 bitmap을 크기별 layout끼리 공유.
- 메모 최대3개 바닥 정렬. 날짜는 중앙에서 2개/3개일 때 위로 이동. 런타임 가로 스크롤 때문에 메모 글자가 안 그려지던 사례를 maxLines=1로 수정하고 실제 픽셀 검사를 추가.
- 셀 XML은 tools/generate_calendar_widget_layouts.py로 생성. 공통5언어 위젯 이름/설명/낮밤 문구 및 도움말 갱신. 한국어 전용 리소스와 공개 웹뷰어 API/키를 삭제하지 않음.
