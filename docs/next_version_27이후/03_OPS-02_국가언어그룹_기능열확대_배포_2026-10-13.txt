03. OPS-02 국가·언어 셀 묶음 / 기능 열 확대 (2026-10-13)

요청/구현
- 미제공/확인 불가 국가를 한 확인 불가 그룹으로 통일한다.
- 국가명은 rowspan으로 언어 행 전체에 한 번만 표시한다.
- 국가 전체의 실제 기간 사용자 규모로 정렬하고 국가 안에서 언어 행을 유지한다.
- 빈 국가와 (not set)는 사용자 중복 가능성이 있어 단순 합산하지 않는다.
  GA4 EmptyFilter(country)로 두 값을 동시에 조회한 union 사용자 수를 사용한다.
  언어/일자 축을 유지하고 API 제한·threshold/누락 메타데이터를 보존한다.
- 알람 끄기를 국가 표에서 제외. 다른 알람 분석의 기존 수집은 유지한다.
- OT·특근 기록, 근무시간 설정, 테마 변경, 근무 지정·변경, 메모 저장, 근무명 변경 추가.
- 신규 사용자는 GA4 newUsers이며 Play 설치 수와 다르다. 시작 완료는 온보딩 완료.
- 언어는 GA4 기기 언어로 앱 표시 언어와 다를 수 있다.
- 알람 생성은 기존 alarm_template_saved(생성/수정 저장), 테마 변경은 달력 테마 이벤트 기준.
- 근무시간 설정에는 기존 수집 이벤트가 없어 dev에서 work_hours_settings_saved를 새로 연결했다.
  월 기준/급여일/OT 계산 설정 및 실제 출퇴근 시각 저장·초기화 성공 때만 기록한다.
  사용자 입력 시간/근무명은 전송하지 않는다. 조회·취소는 기록하지 않는다.
  새 앱 출시 후부터 수집되며 과거 소급 집계 불가. dev Analytics 수집 차단 유지.
