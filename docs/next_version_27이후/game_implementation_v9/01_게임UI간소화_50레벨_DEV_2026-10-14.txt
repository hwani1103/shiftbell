평상시: LEVEL·메뉴 / 보드 / 한 줄 공 선택(무늬·이름·남은 횟수 또는 완료 체크) / 되돌리기·출발.
기존 선택 안내 카드·상태 설명·경로 화살표 목록·상시 힌트·초기화 버튼·다시보기·슬라이더 제거.
다시 시작/도움말/종료는 메뉴. 실패 시 기본 행동은 다시 시작/종료, 경로 보존 수정은 메뉴 보조 행동.
실패한 공 탭으로 자동 편집하던 동작 제거. 실패 장면의 실수 입력으로 상태가 바뀌지 않음.
출발/실패/재설정 때 보드 위치가 변하지 않도록 하단 조작 영역 높이 고정, 짧은 공통 전환/동작 줄이기 적용.
마지막 선택이 별이 아니면 공 선택 버튼과 경로 마지막 칸에 빨간 표시 및 짧은 안내. 되돌리기로 복구.
선택 경로는 진하게, 다른 공 경로는 옅게, 실행 중 모든 경로는 옅게 유지. 장치는 경로 위에 그림.

첫 규칙 안내: 목표·선택 횟수·일정한 칸당 속도/충돌을3장으로 설명. 첫 문 레벨에서 추가 안내.
rulesSeen/gateRulesSeen을 기존 저장 형식의 선택 필드로 저장. 이전 저장은 미확인으로 읽어 안내.
게임 메뉴 도움말에서 규칙을 재열람하고 단계별 힌트도 확인 가능. 안내를 닫아도 경로는 보존.
