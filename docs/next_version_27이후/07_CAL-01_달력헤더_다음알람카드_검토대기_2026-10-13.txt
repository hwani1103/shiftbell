07. CAL-01 달력 년월 우측 다음 알람 표시 카드 — 검토 대기
작성: 2026-10-13

사용자 요청
메인 달력 상단의 년월 표시 오른쪽에 작은 다음 알람 카드를 고려한다.
다음 알람이 있으면 표시하고, 없으면 해당 영역을 비워 둔다.
이번 요청은 문서화이며 앱 구현/예약 로직 변경은 착수하지 않는다.

기존 근거
이 폴더 전체에서는 다음 알람 헤더 카드 문서를 찾지 못했다.
기존 docs/UI 완성도 개선/03_작업지침_원문보존_2026-10-12.txt에는
좌측 년월/우측 다음 알람 요약, 표시 전용(터치·수정·이동 없음),
기존 실제 예약 상태 활용, 작은 화면 배치 및 별도 검증 후보가 있었다.
기존 원문은 보존하고 이 후속 기록으로 연결한다.

표시 계약 후보
- 좌측 년월 표시와 기존 달력 조작 접근성을 유지한다.
- 우측 카드에 기존 다음알람 화면이 판정하는 다음 실제 예약 알람 1개를 표시한다.
- 새로운 예약/선정/저장 경로를 만들지 않고 기존 정렬·제외·연장 알람 규칙을 재사용한다.
- 표시 전용 카드. 탭 이동/수정 기능 없음(기존 합의 유지).
- 내용: 날짜·시간 중심의 작은 요약. 근무명/소리·진동/연장 구분의
  실제 포함 범위와 작은 화면 생략 방식은 구현 전 레이아웃 검토로 결정한다.
- 다음 알람이 없으면 카드/‘다음 알람 없음’ 문구를 표시하지 않는다.
  년월과 조작 요소는 그대로 두고 우측은 빈 영역으로 둔다.
  이 의견이 기존 원문의 ‘다음 알람 없음 표시’ 후보보다 우선한다.
- 로딩·조회 실패·확인 불가는 실제 알람 없음과 상태를 구분한다.
- 카드 색상/타이포/반경/간격/변경 모션은 공통 앱 팔레트·토큰을 참조한다.
- 사용자 지정 근무색이 들어가면 원래 색/글자 계약을 유지하고,
  공통 배경과 비슷한 경우 구분 테두리의 대비를 확인한다.

후속 검증
자연 예약 갱신/추가/수정/취소, 울림 후 다음 대상, 연장 알람,
앱 복귀/날짜 경계, 실제 알람 없음/조회 대기, 긴 근무명,
접힘 좁은 화면/다국어/5개 앱 팔레트와 달력 테마 조합을 확인한다.
알람 기능 변경이 필요한 경우 P0 필수 회귀 기준을 적용한다.
정적·호스트·실기기 검증을 구분하며 표시 성공을 실제 울림 PASS로 확대하지 않는다.

관련 디자인 검토
달력 내부/근무별 사용자 색상은 기존 디자인을 유지하는 방향.
앱 공통 테마 적용 경계·시스템바 분리는 UI29번 원장에 검토안으로 기록한다.
상태: 후보 문서화 완료 / 세부 배치·구현·실기기 검증 미착수.
