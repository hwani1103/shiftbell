ASO-01 — 유입 기준선과 등록정보 개선안 저장 (2026-10-15 KST)

사용자 요청과 최종 범위
- 처음에는 1) 현재 유입 분석, 2) 추천 등록정보 적용·심사제출·승인 시 자동 게시를 요청했다.
- 작업 중 사용자 지시 변경: 이미지를 준비한 뒤 한 번에 게시 검토. 이번에는 작성·저장만 한다.
- 최종 상태: Play Console 변경 10개 저장, '변경사항이 아직 검토를 위해 제출되지 않음' 확인. 검토 제출 버튼 누르지 않음. 자동 검사 실행은 심사 제출이 아님.
- 관리형 게시는 기존 ON 상태 그대로. 승인 후 자동 게시로 전환하지 않음. 이미지 준비 후 실제 제출 시 최신 사용자 의사와 함께 결정한다.

2. 저장한 추천안
- 카테고리: 맞춤설정 → 생산성. 교대근무 달력·계획 관리라는 핵심 용도와 Google 공식 카테고리 예시의 calendar에 맞춤.
- 기존 태그 Calendar / 시계 / 알람 및 타이머 유지. 관련성이 있으므로 5개를 채우기 위한 임의 확장 없음.
- 한국어·독일어·포르투갈어·힌디어 제목은 기존 핵심 용어 보존.
- 영어 제목: ShiftBell – Shift Work Alarm → ShiftBell: Shift Work Calendar (30자). 달력 검색 의도를 제목에 명시하고 자동알람 차별점은 짧은 설명으로 연결. 성과가 검증된 제목이라는 뜻은 아니다.
- 기본 등록정보 5개 언어 짧은 설명: 근무표 변경 시 예정 알람 자동 변경이라는 공통 이점으로 수정. 각 80자 이내.
- 기존 맞춤 등록정보는 한국어·영어 2개 번역만 있음. 이 두 언어의 같은 변경(짧은 설명 2개·영어 제목 1개)을 일치시켜 저장. 나머지 언어를 임의 추가하지 않음.
- 기존 맞춤 타겟: 교대, 교대근무, 교대달력, 알람, 자동알람, 교대알람, 간호사, 소방관, 생산직, 생산직 스케줄, 생산직 달력, 생산직 교대근무. 12개·노출 50%·종료일 없음 유지.
- 맞춤 검토 UI의 실험 정확도 경고를 보존. 기존 목록은 실행 중 스토어 실험 0개였으나 맞춤 50% rollout의 비교 데이터에는 이번 변경이 새 조건이 됨. 과거 데이터와 같은 변형으로 취급하지 않는다.
- 자세한 설명·스크린샷·아이콘·대표 그래픽·영상·출시국·앱 바이너리·리소스·광고·결제 변경 없음. 아직 미출시인 해외 수면 기능을 새 약속으로 추가하지 않음.

3. 최종 검증 및 증거
- 게시 개요에서 기본 6개(설명5+영어제목1), 맞춤 3개(설명2+영어제목1), 카테고리1 = 미제출10개를 확인.
- 이 목록에 이미지·상세설명·태그·노출비율·출시 바이너리 변경은 없음. 입력 길이와 콘솔 저장 성공 확인.
- artifacts/aso_2026_10_15/default_listing_before.json: 기본 5언어 원문.
- artifacts/aso_2026_10_15/custom_listing_before.json: 맞춤 2언어 원문.
- artifacts/aso_2026_10_15/candidates.json: 최종 제목·짧은 설명.
- category_before.txt / custom_target_before.txt / custom_review.txt: 기존 설정 및 검토 기록.
- default_saved.jpg / publishing_pending.txt / publishing_pending.jpg: 저장 및 미제출 증거.
- 생산 코드 수정이 없어 테스트·빌드·기기 검증을 수행하지 않았다. ASO 성과 PASS로 기록하지 않는다.
