GAME-01 구현 인계 설계서 — 2026-10-13
상태: 문서 작성 및 12개 초반 레벨 수학 검증 완료 / 게임 구현 전 / 사람 플레이 테스트 전
사용자 요청: 하위 모델이 게임 구현과 초반 레벨링을 이어갈 수 있는 설계·실행·작업 문서.
현재 작업은 생산 코드, 앱 설정, 빌드, 설치, 배포를 변경하지 않는다.

1. 가장 먼저 지킬 결정
- 한 사람이 모든 Unit의 경로를 미리 설정한 뒤 동시에 실행한다.
- 이동은 거리와 무관하게 한 Step이며, Step 안에서는 직선 등속 이동한다.
- 최대 N회다. N=3일 때 1회 또는 2회에 도착해도 완전한 정답이다.
- 전원 마지막 Step 도착 조건, 조기 도착 해답 제거, 자동 대기 채우기를 사용하지 않는다.
- 첫 버전은 단일 공용 Goal. Goal은 진입 가능한 종착 타일이며 통과할 수 없다.
- Goal 도착 Unit은 즉시 safe 처리 후 논리 세계에서 제거한다. 동시 도착 허용.
- 대기는 금지, 같은 방향 분할·왕복·재방문은 허용한다.
- 충돌은 연속 시간의 중심 좌표 일치로만 계산한다.
- 설정 우측 탭은 dev 실험 후보다. 영구 탭 배치와 출시 여부는 미확정이다.
- 최종 사용자 추가 제약: 기존 앱에 영향이 없어야 한다. 기존 dev 앱도 보호 대상이다.
- 따라서 첫 구현은 별도 실행 프로젝트에서 한다. 기존 앱 연결·탭 추가는 보류한다.
- 포탈, 개별 Goal, 광고, 서버, 로그인은 첫 구현 범위 밖이다.

2. 문서 읽기 순서 (이 문서와 같은 폴더의 game_design_v1/)
01_규칙과범위.txt
  확정 규칙 R01~R15, 설계 기본값, 보류 항목, 이전 문서와의 우선순위.
02_엔진과데이터계약.txt
  순수 Dart 모델/검증/API, 유리수 충돌, 이벤트 순서, 패키지 구조와 확장 경계.
03_UX와dev연결.txt
  경로 입력·수정·재생·실패·저장·뒤로가기, 기존 앱 조사와 보류된 연결 검토.
04_레벨디자인과자동생성.txt
  배치·장애물·Goal 접근·시간 트릭·난이도·Solver·Generator·품질 평가.
05_초반12레벨_설계와검증.txt
  맵, 의도, 실제 해답, 실패 예, 시간 검증, 힌트, 파일럿 순서.
06_구현작업과완료기준.txt
  작업 W00~W09, 의존 순서, 허용 변경, 검사와 완료 증거, 다음 모델 시작 지시문.
07_검증명세와증거.txt
  검증 방법/한계, 테스트 목록, 수학적 증명 범위, 회귀 위험, 출처.
08_pilot_levels.json
  런타임 레벨 데이터의 문서용 원본. 앱 asset 등록은 아직 하지 않았다.
09_pilot_certificates.json
  정답, 전체 개별 경로 목록, 전체 성공 조합, 통계, 쌍별 충돌 증거. 개발용 전용.
10_collision_fixtures.json
  충돌 수학 20종 및 최대 3회에서 1회/3회 도착 허용 회귀 사례.
11_문서검증기록.txt
  실제 수행한 검산, 문서 파일 무결성, 미수행 검증을 기록한다.
12_기존앱무영향_격리계약.txt
  최종 추가 제약. 기존 dev/prod 앱 수정 금지, 독립 실행, 연결 작업 보류의 경계.

03번 문서와 06번 문서만 읽고 UI부터 만들지 않는다.
12→01→02→07을 읽고 격리 범위와 엔진 계약부터 구현한다. 레벨 작업은 04→05→08→09 순서다.
숫자·좌표·분수는 개발자 검증 정보다. 맵 위 사용자 경로 표시에 노출하지 않는다.

3. 기존 기록과의 관계
같은 상위 폴더의 03_GAME-01_동시경로퍼즐_설계검토_2026-10-13.txt,
04_GAME-01_예제9종_경로와시간_검증증명서_2026-10-13.txt,
05_GAME-01_규칙확정사항과_Goal레벨링_2026-10-13.txt는 당시 검토 이력으로 보존한다.
그 안의 미확정 Goal 방식, 정확히 N회 비교안, 전원 최종 도착 제안,
Goal 통과가 포함된 옛 예제는 현재 구현 계약으로 가져오지 않는다.
우선순위: 이후 사용자 지시 > 저장소 AGENTS.md > 본 묶음 01의 확정 규칙 > 나머지 본 묶음 > 옛 검토서.
설계 기본값을 사용자 확정 사항으로 둔갑시키지 않는다.

4. 현재 검증 수준
12개 맵에 대해 가능한 개별 경로를 두 방식으로 완전 열거하고,
경로 조합 359개 중 유효 정답 47개를 확인했다. 이는 서로 다른 레벨의 합계다.
연속 충돌 분석과 독립적인 유리수 후보 전수 대조 결과가 일치했다.
L07은 왕복 없는 정답 0개, L09/L10은 같은 방향 분할 없는 정답 0개다.
따라서 일부 트릭의 필요성은 검증되었다. 모든 레벨이 고난도라는 뜻은 아니다.
L01/L03은 의도적으로 선택 폭이 적은 학습용이다.
재미, 난이도 순서, 1~3분 해결, 터치 편의, 렌더링, Dart 구현, 실기기 알람 공존은 아직 미검증이다.

5. 다음 구현의 제한
문서만 작성하라는 현재 지시는 계속 유효하다. 실제 구현은 사용자가 후속으로 시작을 지시했을 때 진행한다.
그때도 현재 미커밋 변경을 보존하고 dev debug 기준으로 검증한다.
후속으로 게임 구현을 지시하더라도 기본 범위는 독립 프로젝트다. 기존 앱 연결까지 승인된 것으로 해석하지 않는다.
release 빌드, 영구 탭 확정, 운영 광고/알람 변경, 포탈 도입은 이 문서가 승인하지 않는다.
