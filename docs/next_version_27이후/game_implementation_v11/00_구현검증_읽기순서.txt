조작·표현
- 새 스테이지와 다시 시작은 선택 없음. 공 또는 하단 무늬를 직접 고른다. 경로 완성 후 다음 공을 자동 선택하지 않는다.
- 내부 Unit ID는 저장/판정 호환을 위해 유지하며 화면의 A/B/C/D와 힌트의 문자 이름은 색·무늬로 대체한다.
- 선택한 모든 끝점을 깃발로 표시한다. 각 공은 칸의 고정된 모서리를 사용하고 재방문은 겹깃발/작은 점으로 남긴다.
- 포탈은 다회용 고정. 글자·번호·무한 배지를 없애고 기존 링/방향/쌍별 색을 유지한다.
- 번개/창살을 같은 색 열쇠/열쇠구멍 문으로 바꾼다. 테두리 눈금 하나=한 칸 이동 시간이며 재생 중 실제 남은 시간에 맞춰 줄어든다.
- 이동 한도 카운터와 LV 숫자는 유지한다. 스테이지 제목과 챕터 제목은 런타임 문구에서 제거한다.
- 마지막으로 연 레벨을 저장하고 목록 진입/안드로이드 뒤로가기/재실행 때 해당 카드 위치로 이동한다. 파란 3.5px 테두리로 표시한다.
- 기본은 앞 레벨을 완료해야 다음 레벨이 열리는 순차 해금이다. 고정된 상단 잠금 아이콘은 전체 해금과 무한 하트를 함께 토글한다.
- 테스트 토글 자체는 저장하지 않는다. 앱 재실행 시 정상 잠금이며, 이전 테스트 초안은 삭제하지 않고 잠금 뒤에 보존한다.
- 카드 색은1~20 초록,21~30 청록,31~50 금색,51~70 파랑,71~94 보라.95~100은 옅은 빨강에서 진한 빨강으로 간다.
- 카드의 검정/흰색 글자는 실제 배경 명도에 따라 선택하며1~100 모두 대비 검사를 수행한다.
- 기존7열 이하의 최소44px 셀은 유지한다. 마지막8열 보드는320px에서도 전체 열이 보이도록 최소38px를 공통 예외 토큰으로 사용한다.

하트 규칙
레벨마다 독립된3개. 유효한 경로로 '함께 출발'을 실행할 때 하나 차감한다. 일시정지/이어보기/초기화는 차감하지 않는다.
3개를 모두 소진할 때 충전 사이클을 시작한다. 1~2개만 사용한 상태에서 시간이 흘러도 충전하지 않는다.
충전이 시작되면3개까지 계속된다. 중간에 다시 사용해도 누적 충전 시간은 초기화하지 않는다.
앱을 보는 시간60초=1개, 백그라운드·종료 시간3600초=1개. 혼합 시간은 같은 정수 마이크로초 크레딧으로 합산한다.
예: 화면 안30초+앱 밖30분=1개. 앱 안의 목록/다른 레벨에서도 소진된 각 레벨의 충전은 계속된다.
소진 하트는 사라지지 않고 옅게 남는다. 충전 중인 다음 하트는 아래부터 채워진다. 동작 줄이기에서는 보간 애니메이션을 생략한다.
테스트 모드에서는 하트를 차감하지 않는다. 기존 잔여 하트를3개로 덮어쓰지 않으며 토글 해제 후 정상 잔량으로 돌아온다.
서버/광고/새 권한/백그라운드 서비스를 추가하지 않는다. 현지 장치 시각을 이용한 오프라인 규칙이며 부정 조작 방지 서비스는 범위 밖이다.

레벨 인증 방식
기존 constant-cell-speed-v2 규칙 유지. 이동 상한을 파서/검증기 공통 상수16으로 확장한다. 17 이상은 거부한다.
71~100은 기존 장치만 사용, 문 최대2개/포탈 최대2쌍. 71~99는7x7,100은8x8이다.
필수 이동 한도는71~75=6,76~80=7,81~85=8,86~90=9,91~95=10,96~97=11,98~99=12,100=14다.
100은 네 공 모두14회씩 총56회 명령과 총24칸 추가 우회가 필요하다. 정규화 해답은1개이며 원시 명령열 유일해를 주장하지 않는다.
마지막 보드의 충돌 없는 기본 조합21,494개에서 가능한 최대 추가 거리가24칸이다. 같은 보드의 문 제안1,255개를 평가하고 두 문을 결합해 이 상한의 우회를 강제했다.
보스 선정은 사용자가 요청한 필수 이동 수·총명령·우회 거리를 우선했다. 초기 검색의 엔트로피 기반 점수 목표는 탐색 보조 지표이며 사람 난이도 인증값이나 최종 필수 조건으로 사용하지 않는다.
Python 저작기와 Dart 검사는 동일 방향 직선 분할만 정규화한다. 포탈 입구 끝점은 절대 합치지 않으며 왕복/재방문을 모두 탐색한다.
v2에서 포탈을 활성화하지 않는 직선 분할은 궤적·시간을 바꾸지 않고 명령만 늘린다. 따라서 더 적은 명령으로 된 답이 존재한다면 정규화된 답도 존재한다.
전체 정규화 해답의 최소 최대명령이 레벨 한도와 같음을 확인하면, 한도를1 줄인 전체 명령 공간이 UNSAT임을 보인다.
Python은 정수 시각 칸/반시각 간선 점유, Dart는 독립 ray 열거와 두 배 시각·두 배 좌표 점유로 안전 조합을 계산한다.
각 안전 조합은 실제 엔진으로 다시 성공을 확인한다. 문을 하나 제거했을 때 늘어나는 해답과 두 문의 타 공 협동 필요성도 검사한다.
정규화 해답 수와 원시 명령열 수를 혼동하지 않는다. 새30레벨의 원시 명령열 전체 개수나 유일해는 주장하지 않는다.
난이도 점수=후보 선택 지표이며 사람의 해결 시간·실패 횟수의 증명이 아니다. 실기기 플레이/체감 난이도는 미검증으로 남긴다.
