AD-01 메인 달력 배너 로드 실패 후 재시도
상태: 문서화 완료 / 사용자 지시에 따라 지금 수정하지 않음

확인 사실
- AdMob shiftbell_banner(4998796297)는 자동 갱신이 Google 최적화로 활성화되어 있다. 맞춤 120초 설정이 아니다. 콘솔 설정은 변경하지 않았다.
- 앱은 anchored adaptive banner를 사용하며 정상 표시 중에는 SDK의 자동 갱신 정책을 따른다.
- lib/widgets/banner_ad_slot.dart의 onAdFailedToLoad는 광고 인스턴스를 dispose하고 표시 상태를 비운다.
- 같은 크기·방향에서 별도 재시도 예약은 없다. 크기 변경·동의 상태 변경·위젯 재생성 등이 있어야 새 요청이 생긴다.
- 실패 후 폐기한 인스턴스의 재시도는 정상 표시 중 자동 갱신과 별개다. main의 기존 버전에도 같은 실패 경로가 있다.

후속 설계 범위 (미구현)
- 일시적 실패/네트워크 복귀에 대한 제한된 재시도 및 backoff.
- 화면 표시·생명주기·광고 동의·유료 상태를 확인하고 중복 요청 및 폐기 인스턴스 재사용 방지.
- 크기 변경/빠른 화면 전환/앱 백그라운드 시 예약 취소와 복귀 흐름 검증.
- 실제 광고 클릭을 유도하거나 실제 광고 요청을 반복하지 않으며 테스트 광고로 검증.

검증 상태
AdMob 콘솔 설정과 코드 확인 완료. 실패/복귀 재시도의 실기기 PASS는 없음.
